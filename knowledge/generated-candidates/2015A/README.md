## 证据边界

- 内部复现为 `pass` 只说明代码、公式与所报数值一致。
- 对反例可直接定位的逻辑或验证缺陷使用 `fail`。
- 缺源码、视频、独立真值或高精度天文对照时使用 `needs_review`。
- 统一模型重评分依赖 Blind 的太阳公式和二维观测模型，不能替代外部真值。
- 所有提案在跨案例、跨实现验证前都保持 `candidate`。
