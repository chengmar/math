candidate-lessons.yaml 覆盖：

- 本题特有信息：Q4 端点—求积—索引口径。
- 方法卡：有界因果预测控制、时延阶数—运行时选择。
- 失败模式：低扭矩病态比值、同轨迹拟合与评价。
- 验证模式：因果时序、参考结论复现阶梯、旧格式输入溯源。
- 表达经验：分层报告计算、接受性、模型内和硬件证据。
- 不应推广：无题面依据的“优/良/差”阈值。

每张卡都写明适用/不适用条件、最低基线、验证、反例、来源案例和证据强度。任何后续升级都需要跨案例或新证据审查，本阶段不直接升级。
