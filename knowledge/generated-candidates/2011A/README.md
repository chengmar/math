# 2011A lessons proposed

本目录只包含单题复盘候选，不写入核心 knowledge。

- 知识状态只用 `candidate`；若后续材料被确认是 Dummy，其直接衍生项必须改为 `demo`。
- 自动判断只用 `pass`、`fail`、`needs_review`。
- `origin` 严格区分 `independent_blind`、`audit_remediation`、`learned_after_reference` 和组合来源。
- 当前 4 篇 PDF 抽取文本未检测到 Dummy/占位标记，但这不证明材料来源等级。
- 本目录没有任何直接升级项。

文件：

- `case-specific-information.yaml`：本题特有、不可直接迁移的事实与数值。
- `method-cards.yaml`：候选方法卡。
- `failure-modes.yaml`：失败模式。
- `validation-patterns.yaml`：验证模式。
- `expression-lessons.yaml`：表达经验。
- `non-generalizable.yaml`：明确禁止推广的经验。
