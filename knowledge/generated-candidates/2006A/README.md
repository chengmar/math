# Lessons proposed for 2006A reflection

本目录只包含单题 `candidate` 知识，不直接写入核心 knowledge，也不包含 `verified` 条目。

| 文件 | 内容 |
|---|---|
| `case-specific.yaml` | 本题特有数据、约束与已观察结果 |
| `method-cards.yaml` | 可进一步检验的方法卡 |
| `failure-modes.yaml` | 从盲解与参考对照中提炼的失败模式 |
| `validation-patterns.yaml` | 建议复用的验证流程 |
| `expression-lessons.yaml` | 论文与报告表达经验 |
| `non-transferable.yaml` | 不应推广的单题数值和经验 |

Dummy 输入未使用；因此没有 `demo` 条目。所有数学或经济外部效度仍需新的跨题证据与独立审计。
