# 方法卡：污染源定位的点估计与可识别区间

## 动机

相邻站只能观测区间端点。即使负荷守恒成立，源位于区间上游、段中或下游时，反推的原始排放量会因衰减路径不同而变化。只报唯一源强会掩盖这一不可辨识性。

## 候选流程

1. 计算下游负荷减衰减后上游到达负荷，保留有符号净增量。
2. 把正净增量定义为“到达下游的本地贡献”，单位明确为 t/d。
3. 分别假设源位于段首、段中、段末，反解原始源强的下界、中心和上界。
4. 同时对降解系数、传播时间和月份重采样；报告区间排名频率，而非只报均值排名。
5. 总量决策与每公里强度并列，避免长区间天然占优。

## 来源与独立性

- 有符号到达负荷、`k` 敏感性和 bootstrap 是盲解独立形成。
- 源位置上下界由阅读 R622 后才形成；R622 的印刷数值未复现，因此只吸收识别思想，不复制结果。

## 通过条件

- 质量守恒残差在数值容差内：`pass`。
- 下界不大于中心、中心不大于上界：`pass`。
- 参数或结构改变首位时必须报告 `needs_review`，不能删去不稳定情景。

## 失败信号

负增量全部静默截零、不同长度区间直接比总吨数、或把区间首位解释为具体企业责任，均为 `fail`。
