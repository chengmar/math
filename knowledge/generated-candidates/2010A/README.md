# Lessons proposed

本目录只包含本题复盘提出的 `candidate`。没有 Dummy 材料，因此没有 `demo`；也没有任何直接升级记录。

| 文件 | 内容 |
| --- | --- |
| `method-cards.yaml` | 候选方法卡 |
| `failure-modes.yaml` | 候选失败模式 |
| `validation-patterns.yaml` | 候选验证模式 |
| `expression-lessons.yaml` | 候选表达经验 |
| `problem-specific.md` | 本题特有信息与不应推广内容 |

来源标签固定为：`independent`、`audit_corrected`、`reference_learned`。后两者不得改写成初始盲解原创。
