# 候选表达经验

## 应保留

1. 先写 estimand，再写检验名。例如“同一酒样两组均分差”比“做 t 检验”更清楚。
2. 把“内部一致性较高”与“更接近真实质量”分开；前者可以有数据，后者无真值时必须 needs_review。
3. 局部相关、整体映射、质量预测和因果影响分四层措辞，不能互相替代。
4. 等级表末尾附覆盖、互斥、漏列和重复的自动检查结果。
5. 所有 R² 同时给 1-R²；若使用剩余通径，再明确它是 sqrt(1-R²)，避免百分比误读。
6. 报最低基线、外折误差和失败条件；不要只报样本内显著性。
7. 摘要、正文、表格和结构化结果应来自同一数据源或经过自动一致性检查。
8. 一页证据账本列出：主张、数字、基线、反例、状态、文件。

## 应避免

| 表达 | 问题 | 替代写法 |
|---|---|---|
| “方差更小，所以更可信” | 混淆精密度与准确度 | “第二组组内离散较小；无外部真值，准确性 needs_review” |
| “R² 高，模型可评价质量” | 样本内拟合不等于泛化 | “样本内拟合为描述证据；外折相对基线为主” |
| “相关说明影响” | 相关不等于因果 | “在当前样本与控制条件下存在条件关联” |
| “删除异常后关系明显” | 可能事后挑选 | “按预注册规则删点，并并列全样本敏感性” |
| “模型简单易推广” | 没有迁移证据 | “实现简单；跨场景适用性 needs_review” |
| 表和正文给相反结论 | 审计困难 | 由结构化结果自动生成结论句并检查状态 |

## 本题直接反例

- R2 同一章节先报红白总体显著，随后写总体无显著差异。
- R4 的表给白酒 p<.05、红酒 p>.05，正文出现红白标签混写。
- R1 的若干回归表中系数、标准误、t 与 Sig 无法同时成立。
- R2/R3/R4 的等级表出现重复或漏列，但正文仍声称完成分级。

以上经验状态均为 candidate。
