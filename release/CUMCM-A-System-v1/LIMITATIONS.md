# 已知限制

- 系统提供可复现工作流和门禁，不保证模型给出的数学结论必然正确；关键结论仍需人工复核。
- 2022A 替代评测在独立审计阶段因工作区外读取成功而按协议封存，未形成三臂 Blind Final 或有效效果估计；不能据此证明系统有效或无效。
- 22 张训练记忆均保持 `provisional_training`，没有升级为 machine_verified/verified；因此默认推荐可能仍是 `workflow-only`。
- 安全暂停在阶段边界生效，不会粗暴终止正在写盘的模型调用。
- 本包不携带认证信息。真实运行依赖用户已经登录的 Codex CLI。
- Windows 原生沙箱的工作区外只读边界取决于本机 Codex 配置和 ACL；2022A 审计已实际暴露此限制。处理高敏材料时必须把禁止读取的目录另行加 ACL Deny，不能只依赖 `workspace-write` 名称。
- 参考论文复盘不会修改 Blind Final；复盘结论必须与冻结解答分开理解。
