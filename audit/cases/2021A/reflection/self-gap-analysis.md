# 冻结盲解自我差距分析

## 1. 总结

冻结盲解在当前四个对象中拥有最完整的可行性、复现和不确定性证据，但仍有三个实质缺口：焦点被固定为接收圆中心、面形目标主要落在节点而非面板内部、调整后面板的真实曲率/姿态没有工程证据。参考材料没有直接解决这些缺口，却提供了值得重新建模的候选视角。

## 2. 来源归因

### 2.1 盲解阶段独立想到

以下内容在读取批准参考材料之前已经存在于盲解或其冻结前记录中：

1. 用稳定二次根表达径向射线与旋转抛物面的交点；
2. 把问题一固定为连续 300 m 口径最大径向位移最小，并明确该准则是建模偏好；
3. 使用坐标无关的观测轴向量描述任意方位的抛物面；
4. 从附件促动器轴和等长下拉索反算行程，而非把节点径向位移直接当作最终行程；
5. 对精确边长、行程、拉索闭合和六位输出作结构化检查；
6. 使用分片平面几何光学、投影功率权重和固定种子低差异采样。

R1 的连续最小最大候选、R2 的平面基准接收比与这些内容相近，只能视为独立交叉吻合，不能倒推为看参考后获得。

### 2.2 审计后、读取参考前修正

以下内容来自冻结 V1 的独立审计反例，已经在最终冻结盲解中完成，不能归为参考材料贡献：

1. 把焦距与节点位移联合选择，替代“先固定连续理想面、再调节点”的串行流程；
2. 将人为 0.060% 线性帽改为经精确/舍入复核的 0.062%，并报告 0.063% fail；
3. 加入一参数统一缩放可行基线与冻结 V1 基线；
4. 实现分片平面与继承球面曲率两个条件包络，保留面板解释 needs_review；
5. 重画完整加权光斑并把 6 m 图明确为局部图；
6. 增加文档控制字符检查、确定性复跑和证据边界。

因此，“双面板模型”“简单基线”“联合焦距—节点设计”属于审计后修正，而不是看 R1/R2 后学到。

### 2.3 读取参考后才学到或明确形成

1. **有限接收区可定义焦点区域。** R3 不把焦点固定在接收圆中心，而允许其沿轴线在仍可命中有效区的范围内移动。R3 的具体实现违约，但“点焦约束改为焦域约束”的自由度在 BF 中确实缺失，属于看参考后形成的 candidate。
2. **面形目标可加入面板内部求积点。** R1 用节点和圆弧中点评价/微调面板贴合度。其 3 mm 结果缺少全约束证据，但它揭示 BF 的节点径向 RMS 未直接惩罚面板内部法向和曲率误差，属于看参考后形成的 candidate。
3. **算法框与证据表可以并列。** R2 的编号算法框比 BF 的纯公式叙述更容易复查。应保留 BF 的状态/证据表，同时增加简短伪代码，而不是复制 R2 的语言或结构。
4. **四种问题一目标形成了可展示的目标族。** BF 在审计前已经知道准则不唯一，但看到 R1 的总伸缩、R2 的面积平方误差和 R3 的最大边变化后，才形成 \(L_\infty/L_1/L_2/应变\) 的完整比较图景。这是比较集内的认识增强，不是首次发现“目标会影响解”。

## 3. BF 相对参考材料的优势

1. **可行性证据。** BF 给出全边、行程、闭合与舍入复核；R1/R2 缺完整残差，R3 明确违约。
2. **模型不确定性分层。** BF 把数值收敛 pass 与面板解释、外部物理 needs_review 分开；参考材料多把内部稳定直接写成结果合理。
3. **复杂度基线。** BF 同时列一参数、冻结 V1、审计锚点与联合方案，并承认联合方案的最大误差更差。
4. **复现。** BF 两次运行的 21 个确定性文件同哈希；参考只含扫描附录，无法可靠执行。
5. **反例意识。** BF 保留问题一准则、问题三几何、真实馈源方向图等失效条件，没有把单一数字写成工程真值。

这些优势不构成世界首创或形式化正确性证明，只说明相对当前比较集的证据质量更高。

## 4. BF 的具体缺口

### G1：焦点固定过强

BF 强制理想抛物面的焦点等于馈源有效圆中心。有限半径接收区允许一个焦点容差区域的可能性没有进入问题一或问题二。R3 的候选说明增加该自由度可能改变焦距与边长折中。

- 当前状态：needs_review；
- 风险：增加自由度可能降低面形代价，也可能使离焦射线在口径边缘越出接收圆；
- 所需验证：把“焦点位置”改为变量后，必须用全口径逐射线命中而非只检查焦点坐标。

### G2：节点目标不能代表面板内部误差

BF 主目标是 692 个活动节点的径向残差 RMS。面板内部的法向、曲率和焦面命中没有参与问题二选型，只在问题三事后评价。R1 的边中点做法提示可在每块面板加入固定求积点。

- 当前状态：needs_review；
- 风险：节点 RMS 更小的方案可能有更差的面板内部最大误差或光斑；
- 所需验证：同时报告节点 RMS、面板求积 RMS/最大值和接收比，但保持问题三评价集不反向泄漏到未经声明的模型选择。

### G3：精确非线性约束只在投影后验收

BF 内层优化使用线性应变帽，最终再按精确三维边长验收。0.062% 的选择有网格证据，但没有直接求解精确非线性可行域，也没有形式化全局下界。

- 当前状态：needs_review；
- 风险：线性帽可能排除更优的精确可行解；
- 所需验证：以 BF 解为暖启动，至少增加一个直接非线性约束求解器或可验证区间下界；仍需复核六位输出。

### G4：面板物理仍未辨识

BF 的 28.966% 与 1.060% 都是条件模型。R1 和 R2 分别支持两类基准值，但不能确定调整后面板是保持球面曲率、刚体旋转、弹性变形还是其他状态。

- 当前状态：needs_review；
- 风险：模型差异远大于数值误差；
- 所需证据：面板制造曲率、支承方式、调整后测量法向或题面明确规则。

### G5：结构力学与切向自由度缺失

BF、R1–R3 都主要使用几何运动学。索网张力、切向位移、面板刚度和边界支承没有进入优化。

- 当前状态：needs_review；
- 风险：几何可行不等于受力可实现；
- 所需验证：至少加入线性化索网平衡或把几何模型明确限定为上层设定值生成器。

### G6：多目标取舍仍不足

BF 联合方案的径向 RMS 最好，但最大正交误差 0.252213 m 高于一参数基线 0.190383 m 和冻结 V1 0.186193 m。当前只披露这一代价，没有构造完整 Pareto 前沿。

- 当前状态：needs_review；
- 改进：以 RMS、最大误差、最大行程、边长余量、计算时间和接收比构造小规模 Pareto 表，不把单指标最小写成总体最优。

### G7：计算成本与表达负担偏高

BF 记录单次运行约 255 s，且读者需要在论文、验证 JSON、CSV 和审计报告之间跳转。参考材料的算法框和流程图更快建立整体认识。

- 当前状态：needs_review；
- 改进：给出 10–15 行伪代码、计算规模表和“结论—状态—证据文件”索引；保留详细证据作为附录。

### G8：外部与排版验证未完成

BF 没有真实工程数据、馈源方向图或面板测量数据；当前环境也没有 XeLaTeX，实际编译与逐页检查保持 needs_review。

## 5. 修订优先级

### P0

1. 构造“焦点区域 + 面板内部求积 + 精确约束”的小规模候选模型；
2. 保持两种面板几何包络，不用参考论文的单一结果裁决真实模型；
3. 对 R1 顶点不变量、R3 约束违例这类基本检查设置自动 fail 门槛。

### P1

1. 生成多目标 Pareto 表；
2. 用第二求解器检查线性帽排除的精确可行改进；
3. 在论文中加入紧凑算法框和证据索引。

### P2

1. 获取受控批准的面板工程信息后再裁决曲率模型；
2. 在具备 TeX 的干净环境编译并逐页检查；
3. 只有跨题复现和人工审核后，才考虑把 candidate 提交到更高知识层级。

## 6. 边界声明

本分析没有修改冻结盲解，也没有把审计报告的 fail 当作 reflection 进入失败。所有新认识均只写入 `candidate`；没有因参考论文被称为优秀材料而默认其数学结论为 pass。
