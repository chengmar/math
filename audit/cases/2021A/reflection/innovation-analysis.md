# 相对当前比较集的创新分析

## 1. 口径

这里的“新”只指相对 BF、R1、R2、R3 这四个对象的组合差异或实用收益。没有进行文献检索，因此不宣称世界首创、学术首创或工程首创。参考论文也不因获批进入比较集而默认正确。

## 2. BF 在当前比较集中的独特组合

### 2.1 焦距—可实现节点联合选择

R1–R3 都先确定或继承一个理想抛物面，再调节点；BF 在审计后把焦距与 692 个节点位移放入外—内层联合框架，并用已知审计锚点与全焦距包络检查所选主目标。

- 相对差异：当前比较集中只有 BF 明确给出该联合搜索及可核验候选表；
- 实用收益：避免连续理想面最优却离散不可实现的串行错配；
- 局限：内层仍使用线性应变帽，形式化全局最优性为 needs_review；
- 来源：审计后修正，不是读取参考后获得。

### 2.2 精确—舍入双重可行性

BF 对精确坐标和六位输出分别检查边长、行程与拉索闭合。R1–R3 没有给出同层次的舍入后验收。

- 相对差异：pass；
- 实用收益：避免理论可行解在提交格式舍入后失效；
- 可推广性：candidate，需跨题验证后才能升级；
- 来源：盲解/审计前后内部形成。

### 2.3 面板几何双包络与证据分层

BF 同时给出继承球面曲率和分片平面两种条件结果，并把数值收敛 pass 与面板解释 needs_review 分开。R1 只走球面片路线，R2 只走平面片路线，R3 用修正面积比。

- 相对差异：当前比较集内最强；
- 实用收益：R1 的 5.27% 和 R2 的 0.811% 恰好分别支持两个基准包络，证明“双答案”不是多余计算；
- 局限：双包络仍不包含刚性曲面姿态、弹性面形或实测法向；
- 来源：审计后修正，不是参考后学习。

### 2.4 复杂度—收益基线与非 Pareto 披露

BF 同时报告一参数基线、冻结 V1、联合方案，并承认联合方案的最大误差更差。参考材料多直接称所选结果“最优”或“合理”。

- 相对差异：解释性和证据边界更强；
- 实用收益：把 693 参数模型的收益与代价显式化；
- 局限：尚未形成完整 Pareto 前沿。

## 3. 参考材料中 BF 没有的候选想法

### 3.1 有限接收圆对应焦点区域

R3 把馈源有效区从一个固定焦点转化为允许焦点沿轴移动的区域。R3 的具体解不满足 0.07% 约束，不能直接采用，但这个自由度本身值得受控重建。

- 看参考后才形成：是；
- 候选价值：可能降低面形/边长代价，或形成更合理的离焦鲁棒设计；
- 必要修正：不能只判断焦点落在几何区间，必须逐射线验证全口径命中；
- 状态：candidate，数学与物理有效性 needs_review。

### 3.2 面板内部求积点参与问题二目标

R1 在节点之外使用圆弧中点评价局部面板贴合，并进行快速微调。其 3 mm 结果缺少题面全约束证明，但它指出节点 RMS 与面板内部误差不是同一个量。

- 看参考后才形成：是；
- 候选价值：使问题二的选型指标更接近问题三法向/光斑误差；
- 必要修正：用固定重心求积点替代依赖不明球心的圆弧构造，纳入精确边长、行程和闭合约束；
- 状态：candidate。

### 3.3 算法框与证据表双层表达

R2 用编号算法框描述二分、BFGS 和蒙特卡洛，流程容易复查。BF 的证据表更强，但算法叙述较密。

- 看参考后才形成：表达层面的明确改进；
- 候选价值：让读者先获得计算流程，再进入 KKT、哈希和敏感性细节；
- 限制：只学习表达机制，不复制参考论文语言、结构或无证据的“最优”措辞；
- 状态：candidate。

## 4. 综合候选：焦域—面板—约束三层设计

相对当前比较集，可以提出一个新的组合候选：

1. 外层变量：焦距和焦点在有效接收区中的轴向位置；
2. 中层变量：活动节点位移，直接受精确边长、促动器行程和拉索闭合约束；
3. 面形目标：节点残差与每面板固定求积点残差的多目标组合；
4. 后验评价：平面片、继承曲率和必要时第三种工程面板模型下的接收比；
5. 输出：RMS、最大误差、行程、边长余量、运行时间和接收比的 Pareto 表；
6. 证据：精确/舍入复核、第二求解器或下界、分辨率/种子敏感性。

该组合把 R3 的焦域、R1 的面板内部点和 BF 的联合约束/双包络连接起来。它相对当前四个对象是新的组合，但尚未实现和验证，状态只能是 candidate。

## 5. 不应包装为创新的内容

1. 坐标旋转、BFGS、蒙特卡洛、Sobol、二分法本身是通用工具，不因用于本题就成为创新；
2. 得到不同焦距不是创新证据，往往只是目标函数不同；
3. 随机波动小只证明数值稳定，不证明面板模型正确；
4. 约束只超 0.04% 左右仍是 fail，不能写成“工程创新性放宽”；
5. 未定义修正系数带来的结果改善不能视为方法创新；
6. BF 的确定性复现、哈希和 KKT 是证据质量，不等于数学方法首创。

## 7. 升级条件

以上任何方法卡都不能直接成为 verified。至少需要：

1. 在本题冻结附件上独立实现并给出精确/舍入可行性；
2. 与 BF、一参数基线和已知审计锚点比较；
3. 对不同面板解释保持条件化结果；
4. 在额外题目或受控工程数据上复现；
5. 由人工审核确认适用边界和非泄漏 provenance。
