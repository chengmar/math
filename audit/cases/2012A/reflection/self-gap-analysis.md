# 冻结盲解自我差距分析

- 产物状态：candidate
- 基准：blind-final 与当前 4 篇批准参考的相对比较
- 边界：不修改冻结盲解；不把参考论文当标准答案；不升级 verified

## 总体判断

B0 的主要优势不是模型名称更复杂，而是问题单位、验证边界和证据状态更严格：保留酒样配对、检查等级全集、把局部关系与整体预测分开、使用折内处理和最低基线，并把无法由附件解决的问题保留为 needs_review。主要短板则是外部真值缺失、模型计算成本高、结果对工作评委组仍敏感，以及评分构成和化学机制结构尚未系统建模。

## 独立想到、审计修正、参考后学习

### 独立想到

1. 以同一酒样为配对单位比较两组评分。
2. 不把第一组称为真实更准确，只作下游工作目标。
3. 用等块 PCA–Ward 给暂定等级，并用另一评分组做敏感性。
4. 同时报告局部理化关系和整体跨块预测，拒绝用局部相关代替整体映射。
5. 以训练均值为最低基线，得出理化指标不能替代感官的保守结论。

这些内容在 blind-v1 已存在，早于参考材料读取。

### 审计后修正

1. Monte Carlo 符号翻转改为动态规划精确枚举。
2. 入口自包含，输入字节和语义提取均留哈希。
3. 芳香筛选、填补、参考量、缩尾与标准化全部折内拟合。
4. log1p(x) 改为 log(1+x/x_ref)，并做 0.001/1000 倍单位反例。
5. 小样本 Spearman 改保留并列的高重复置换并统一 BH。
6. Q4 联合选择 scope/family/参数，主结果改为选择感知推断。
7. 增加物理支持约束、Q² 基准拆分、秩/零空间和单变量不可辨识政策。

### 看参考后才学到

1. 参考论文普遍对评分分项重新加权，提示“总分构造”本身应作为目标敏感性；但熵权不是自动正确答案。
2. 多篇材料按酸、酚、色素、芳香等讲解，提示可以预注册化学组并做组级消融，提高解释性。
3. 多篇等级表出现重复/漏列，提示成员覆盖与互斥必须成为发布门槛，而不只是代码内部检查。
4. 通径/桥梁叙事有表达吸引力，但在小样本、逐步筛选和无预设因果图时会产生虚假机制感；若未来使用，必须先声明机制与识别条件。
5. 分项终点的并行报告有助于解释“总体差异来自何处”，可作为 Q1/Q4 的辅助层，但不能把多次分项检验当总体结论。

## 优先级

1. 首要：获得独立年份/产区及外部质量校准，解决 Q1 可信组与 Q4 外部有效性；当前状态 needs_review。
2. 次要：把评分构成敏感性和化学组级验证加入候选流程；当前状态 candidate。
3. 再次：用自适应 Monte Carlo 与更清晰证据账本降低成本、提升表达；当前状态 candidate。
4. 不建议：在现有 27/28 样本上继续增加非线性模型或逐步回归变量；当前判断 fail。
