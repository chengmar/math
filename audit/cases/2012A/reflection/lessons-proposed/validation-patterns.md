# 候选验证模式

## VP-01 匹配单位检查

- 适用：同一对象多条件测量。
- 最低基线：独立检验。
- pass 条件：对象 ID 一一配对，差值定义清楚，配对与置换实现一致。
- 反例：R3/R4。
- 状态：candidate。

## VP-02 分区集合检查

- 适用：等级、聚类、分层名单。
- 最低基线：人工计数。
- pass 条件：全集覆盖、互斥、范围正确、成员数相等、表文一致。
- 反例：R2/R3/R4。
- 状态：candidate。

## VP-03 选择感知嵌套验证

- 适用：预处理、特征范围、模型族或参数由数据选择。
- 最低基线：每个外折训练均值和简单正则模型。
- pass 条件：所有选择进入内层，外折只评估，拟合 ID 与验证 ID 无交集。
- 反例：参考材料的样本内逐步回归。
- 状态：candidate。

## VP-04 小样本多重检验

- 适用：大量相关或系数检验。
- 最低基线：渐近 p + BH。
- pass 条件：检验族预定义；小样本用保留并列的置换；报告 Monte Carlo 区间和边界稳定性。
- 反例：R1/R2/R4 的事后筛选。
- 状态：candidate。

## VP-05 量纲反例

- 适用：有单位变量及非线性变换。
- 最低基线：标准化前后比较。
- pass 条件：物理等价单位换算后选择、预测和主指标在容差内不变。
- 反例：审计前 log1p(浓度)。
- 状态：candidate。

## VP-06 干净入口复现

- 适用：交付代码与论文。
- 最低基线：原目录重复运行。
- pass 条件：从无 results/figures/PDF 的隔离副本运行；退出 0；生成路径集合一致；非 PDF 字节或 PDF 语义一致；无网络、无跨阶段调用。
- 本题证据：blind-final/results/reproduction-test.json。
- 状态：candidate。

## VP-07 外部有效性闸门

- 适用：声称质量评价、等级标准或替代人工。
- 最低基线：重复交叉验证。
- pass 条件：独立年份/产区/实验批次，目标构造预锁定，达到预注册性能门槛。
- 当前本题：needs_review。
- 状态：candidate。
