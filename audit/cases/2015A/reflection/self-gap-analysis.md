# 2015A 冻结盲解自我差距分析

## 总结

冻结盲解的主要优势不是“结果与参考论文更接近”，而是模型、数据、分支、失败项与复现证据能够相互追踪。其内部实现一致性为 `pass`，外部真值仍为 `needs_review`。当前最重要的差距是：缺少独立真值与真实视频标定、问2存在前缀漂移、OLS 在污染压力测试中为 `fail`，以及太阳公式版本误差尚未由独立历书裁决。

本分析不改写冻结盲解，也不把审计报告原有的总体 `fail` 改成 `pass`。以下改进项均只是 `candidate`。

## 结果层面的具体诊断

### 问1

Blind 报告 11:58:33、3.662758 m；本轮“简化赤纬且关闭均时差”的消融给出 12:14:26、3.841053 m，与 R4 自报数值接近。R4 正文也列有均时差式，故不能反推其代码一定关闭了均时差。两套可计算结果都不等于外部天文精度证明；独立高精度太阳历缺失时，裁决为 `needs_review`。

### 问2

Blind 主分支的端点 RMSE 为 0.346472 mm，统一模型下优于四篇材料公开候选；R3 的同模型端点 RMSE 为 1.366927 mm，地理中心距 Blind 约 27.1 km。与此同时，Blind 的前缀漂移为 `fail`，所以小残差不应被表达成高精度地理定位。下一步应先解决时间相关模型失配，再讨论经纬度小数位。

### 问3

Blind 在附件2和附件3都保留两支季节候选，而不是强行择一；这是可辨识性表达上的进步。缺口在于尚无外部信息打破季节配对，故“多支保留”是诚实边界，不是最终消歧。任何唯一日期结论仍为 `needs_review`。

### 问4

冻结修订已把单应方向、齐次归一化和量纲问题改正，合成自洽为 `pass`。真实视频数值应用仍为 `fail`，这是数据门槛而非应被补写的空白。R2 的帧相位敏感性和 R4 的杆高敏感性可成为后续真实数据实验的两个必做消融。

## 改进优先序（均为 candidate）

1. 先建立已知真值的外部盲测与高精度太阳历对照；否则内部 RMSE 再小也不能升级为外部正确。
2. 在保留解析旋转—尺度消元的前提下实现稳健损失，并用冻结污染方案做同表对照。
3. 对问2执行预注册的窗口稳定性分析，明确何种漂移阈值会触发拒绝给出高精度坐标。
4. 只有在视频、时间戳、控制点和杆几何齐全后才运行问4数值反演，同时加入帧相位和杆高敏感性。
5. 把复杂度、随机性、人工筛选规则和失败分支写成可复现实验清单；把完整审计材料放入附录。
