## 4. 结果层面的相对发现

1. B 的 2005 处理量 `75.207` 与 R178 的 `75.195` 几乎相同；B 的十年合计 `1330.936` 只比 R1BE 的 `1390.621` 低约 4.49%。这可作为量级交叉检查，状态为 `pass`，但不是正确性证明。
2. B 的允许未处理当量 `215.293` 亿吨略低于 R622 枯水期阈值 217，说明二者虽推导不同，却落在相近控制尺度；状态为 `pass` 的相对事实。
3. B 与 R869 的 2014 非饮用比例分别为 55.27% 与 55.80%，方向和量级一致；R1BE 的 99.38% 非饮用和 R622 枯水干流的 98.50% 非饮用说明水期与模型结构可主导结果，精确预测状态为 `needs_review`。
4. Q2 中 NH3-N 首位对宜昌—岳阳较一致，而 CODMn 在 R869 中改为九江—安庆。该分歧证明“估计对象和源位置假设”必须随结果一起报告。

## 6. 候选创新组合

最有实用收益的后续组合不是增加算法名，而是：

1. Q1：法规等级 + 阈值裕量辅助分值；
2. Q2：到达负荷点估计 + 源位置上下界 + 参数/结构双层敏感性；
3. Q3：滚动基线 + 单纯形约束 + 残差区间 + 模型结构情景；
4. Q4：安全压力中心值 + 枯丰水场景 + 去除效率层；
5. 全链：数值复现、二进制哈希和视觉等价三类证据分开报告。

该组合仅形成 `candidate` 方法路线。
