# 冻结盲解自我差距分析

`overall_status: needs_review`

## 1. 来源分层

### 独立想到

下列内容已存在于冻结 V1，最终数值模型没有因阅读参考材料而改变：

1. 法规最差指标定级为主、连续 Nemerow 指数为辅；不让数据驱动权重覆盖国标等级。
2. 以流量×浓度做负荷守恒，保留负净增量作稀释/误差诊断；对 `k=0,0.1,0.2,0.5` 做敏感性。
3. 用扩展窗口、简单基线和时间顺序无泄漏规则选择短序列模型。
4. 把水质构成投影到非负且总和为 100% 的单纯形，并用 bootstrap 报告宽区间。
5. 用历史安全污染压力包络规划处理当量，并单独给出去除效率换算。
6. 明确全局比例只是等权断面月次比例，另报干流与支流/湖口。

证据：V1 与最终 `<SOURCE_FILE_REDACTED>`、`<SOURCE_FILE_REDACTED>` 完全同哈希；`solve_case.py` 的实质差异只是为滚动验证增加训练起止年和样本数。`key_results.json` 的差异仅在约 `1e-13` 量级的浮点末位。

### 审计后修正

独立审计因旧清单 PDF/日志哈希不一致而停止，没有提供数学模型修正意见。盲修订新增的是证据链，而不是参考答案对齐：

- 重复性脚本改为真正重跑 `extract_docx -> build_data -> solve_case`，不再用遗留入口替代主链。
- 滚动验证明细加入 `training_start_year`、`training_end_year`、`training_count`，并自动检查训练截止年早于验证年。
- 固定 TeX 编译、即时取哈希、最终核验、清单生成和只读复核顺序；扩大暂存清单覆盖。

这些修订当时对暂存树为 `pass`，但外部冻结后的当前 PDF/日志与旧暂存哈希不同，当前包内暂存清单复核为 `fail`。外部 305 项权威清单仍逐项 `pass`。这暴露的是“阶段间构建物可能被重新生成”的证据链差距，不能被包装成数学修正。

### 看参考后才学到

1. R622 把未知源位于区间何处转化为源强上下界；这比单一点估计更直接表达不可辨识性。
2. R622 按枯水、丰水和水文年分别给处理能力，提示把水期结构不确定性与统计 bootstrap 分开报告。
3. R178 用多种物理简化反演同一源区，提供“结构模型三角互证”的验证模式。
4. R622/R869 的阈值敏感动态权重可作为同一法规等级内的辅助严重度指标，但不应替代最差项定级。
5. R622 对常见答卷失败方式的归纳提示：源量需按区间长度或暴露尺度可比，比例预测必须闭合，Q4 应复用 Q3 的映射而不是另起一套无关模型。

## 2. 已有优势与边界

| 维度 | 冻结盲解已有优势 | 仍然不能声称 |
|---|---|---|
| 模型 | 低复杂度、法规和质量守恒语义清楚；多数参考使用更复杂组合但无更强外推验证。 | 低复杂度模型就是物理真相。 |
| 结果 | 最差站、主导污染物、NH3-N 重点区间和十年恶化方向得到多篇交叉支持。 | 交叉支持等于正确；参考共享数据和相近假设。 |

| 解释性 | 结果可落到断面、区间、年份、压力阈值和去除效率。 | 区间首位等于具体企业或行政区责任。 |

## 3. 重点差距

### G1：Q2 只给点估计，没有把源位置不确定性传播成区间

- 当前做法：把净增量视为到达下游站的本地贡献，得到一个平均正负荷。
- 参考启发：同一观测端点下，若源靠近上游或下游，其原始排放量会因衰减路径不同而变化；R622 用上下界表达这一点。
- 差距影响：B 的区间排序较稳，但绝对源强看起来比其识别能力更精确。
- 改进候选：对每个“月份×区间×污染物”同时报到达负荷与源位置上下界，再分别做 `k` 敏感性和 bootstrap 排名。
- 状态：`candidate`；R622 的印刷表值未复现，需重实现而不能照抄。

### G2：Q4 的流量不确定性存在于 CSV，但论文主表没有水期情景

- 当前做法：中心情景用平均流量，CSV 提供历史流量重采样区间，建议中只说枯水年更严。
- 参考启发：R622 直接给枯水/丰水允许排放 217/230 亿吨和年度处理区间。
- 差距影响：工程读者容易只看到单个 75.2—191.0 序列，忽略水期条件。
- 改进候选：主表并列中心、枯水、丰水或经验分位情景，并保持同一安全压力与去除效率定义。
- 状态：`candidate`。

### G3：Q1 同等级排序的解释还可加强

- 当前做法：Nemerow 指数辅助，但论文主结果主要报告平均等级和类别比例。
- 参考启发：R622/R869 的连续阈值权重突出跨 III/IV 边界的指标，并能形成长期名次。
- 差距影响：两个同为 III 类的断面可能风险幅度不同。
- 改进候选：保留国标等级为主结果，另报“距最近更差等级阈值的裕量”或阈值敏感连续分值；不使用主观动态权重改变法规结论。
- 状态：`candidate`。

### G4：Q2 缺少结构模型三角互证

- 当前做法：只比较不同 `k`，没有系统比较“源在段中点”“源位置上下界”“含支流混合”三种结构。
- 参考启发：R178 的多种反演结构虽未完整复现，但验证思想有价值。
- 差距影响：当前 bootstrap 只覆盖月份抽样，不覆盖模型结构误差。
- 改进候选：构造最小的三模型集合，报告首位区间在参数与结构双层扰动下的稳定性。
- 状态：`candidate`。

### G5：Q3 的不确定区间未覆盖制度和监测口径变化

- 当前做法：残差 bootstrap 反映采样残差，且已经明确这一边界。
- 参考对照：各文从 0.62% 到 44.73% 的十年末可饮用比例差异，说明结构选择远大于普通残差。
- 差距影响：80% 区间可能仍低估结构性不确定性。
- 改进候选：除统计区间外，单独给模型集合区间、监测口径断点情景和治理政策情景。
- 状态：`needs_review`；当前材料不足以标定断点概率。

### G6：处理量到水质类别的因果映射仍为空缺

- 当前做法：安全压力包络比小样本多元回归更保守、更易解释，但仍是经验代理。
- 参考对照：R178、R1BE、R622、R869 也都依赖回归阈值或允许排放上限，没有提供处理工程到类别变化的因果剂量响应。
- 差距影响：所有处理量只能解释为规划当量，不能承诺“无劣 V 类”。
- 状态：`needs_review`；这不是从现有四篇材料可以补齐的缺口。

### G7：冻结包内部暂存证据失配

- 当前事实：权威外部清单 305/305 哈希 `pass`，但包内旧暂存清单对当前 PDF/日志为 `fail`。
- 影响：阅读者若只看 `final-verification.json` 会误以为旧哈希仍描述当前文件。
- 改进候选：外部冻结清单应记录生成后允许新增的证据文件，并把构建物的语义等价检查与二进制哈希检查分开。
- 状态：`candidate`；不得修改当前冻结历史。

## 4. 结果差异的实质解释

| 结果 | 冻结盲解 | 参考范围 | 差异主要来自 |
|---|---:|---:|---|
| 2014 可饮用比例 | 44.73% | 0.62% 到 44.20%，R622 水文年干流 37.56% | 聚合类别、模型结构、水期、删点和平滑 |
| 2014 废水排放 | 406.27 亿吨 | R622 469，R869 531.32 | OLS、GM 和后续线性化的增长率 |
| 2005 处理量 | 75.207 亿吨 | R178 75.195；R622 73–86；R869 171.42 | 允许排放阈值；R869 上限明显更低 |
| 2014 处理量 | 190.980 亿吨 | R178 198.87；R622 239–252；R869 399.73 | 废水预测与允许排放共同作用 |
| Q2 CODMn 首位 | 宜昌—岳阳 | 多数支持该段，R869 为九江—安庆 | 源强定义、源位置、衰减、负值处理、长度归一 |

差异本身是反思证据：最终数字不是模型名称的附属品，而是“估计对象 + 单位 + 参数 + 约束 + 验证口径”的共同产物。

## 5. 改进优先级

1. 高优先：Q2 源位置上下界与结构敏感性；能直接纠正点估计的过度精确感。
2. 高优先：Q4 把流量/水期情景提升到论文主表，并保留去除效率层。
3. 中优先：Q3 增加模型集合与口径断点情景，继续保留滚动基线。
4. 中优先：Q1 增加阈值裕量辅助排序，不改变法规等级。
5. 高优先的流程项：后续冻结流程分开报告权威全树哈希、构建物二进制稳定性与视觉/数值等价性。

所有改进均只形成 `candidate`；当前单题材料不支持直接升级。
