# 代码说明

入口为 `solve.py`，仅依赖 Python 3.8+ 标准库。

运行：

```powershell
python code/solve.py
```

当前机器的 `python` shim 不可用，实际复现命令见根目录 `reproducibility.yaml`。程序执行以下流程：

1. 求问题 1 的 12 m/s 与 24 m/s 平衡；
2. 求问题 2 原方案并二分配重阈值；
3. 实现单杆基线、无重量直链候选和分段悬链线主模型的同输入比较；
4. 枚举五种链型、整数链环数与配重，筛选问题 3 方案；
5. 对入选方案复算 33 个非静风/流组合，完成敏感性和独立积分验证；
6. 生成 CSV、JSON、TeX 数字/表格以及 SVG/PDF 图。

程序无随机过程。输出清单和 SHA-256 位于 `results/generated-manifest.json`。

物理模型的核心限制是题面没有锚链线径和重物球材料：主结果不计链流阻，并以钢质球为基准；代码另做水平荷载放大和球密度敏感性测试。不要把程序残差 `pass` 解释为海试外部有效性。
