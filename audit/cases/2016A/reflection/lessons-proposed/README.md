## 来源分层

- 独立想到：分段刚杆/悬链线/海床接触、基线比较、Pareto 固定尺度框架。
- 审计后修正：球三参数与球节点、完整整数链环和配重域、干净清单与回归反例。
- 看参考后才学到：风流三维情景、垂向剖面候选、离床临界点、固定部署不变量、AHP 一致性检查。
