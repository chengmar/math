# 2016A 相对创新与实用增益分析

## 1. 声明边界

本分析没有进行文献检索，不能判断世界首创、国内首创或竞赛历史首创。以下“差异化”只相对于最终冻结盲解 B 和批准材料 R1–R4；所有可提炼经验只进入 `candidate`。

## 2. 冻结盲解相对当前比较集的差异化

| ID | 内容 | 来源分类 | 比较集差异 | 证据状态 | 实用收益 |
|---|---|---|---|---|---|

这里的 `pass` 只表示“在当前比较集内有直接文件证据且实现成立”，不表示外部工程有效性。

| ID | 候选方向 | 来源 | 当前判断 | 采用前提 |

## 4. 不构成相对创新的内容

| 内容 | 判断 | 原因 |
|---|---|---|
| 静力平衡、力矩平衡 | fail | 五对象共同基础 |
| 连续悬链线与海床接触 | fail | B、R1、R4 均使用，R3 也有着地修正 |
| 二分/遍历/粗细搜索 | fail | 属于常规数值工具，且参考中反复出现 |
| 选择 V 型链 | fail | 五对象结论相近，但选择结果不是方法创新 |
| 使用 Pareto、AHP、熵权或遗传算法名称 | fail | 名称本身不提供可行域完整性、收敛或外部正确性 |
| Q1/Q2 数值与参考接近 | fail | 相近可能来自共同假设，不能作为新颖性证据 |

## 5. 实用创新比“算法新名词”更重要的部分

1. **接口创新**：以 `m_eff,V,d_h` 组织工程输入，使缺数据的位置可见、可替换。
2. **证据创新**：把审计反例、残差、网格收敛和干净哈希放进同一追溯链。
3. **设计域创新**：把整数制造约束和连续配重同时纳入，而不是先把配重压缩为每链一个点。
4. **表达创新**：把“模型内 pass”和“真实海况 needs_review”紧邻结果书写，减少过度承诺。

上述四点均只能描述为当前比较集内的实用增益；未经更广材料与跨题验证，不升级状态。
