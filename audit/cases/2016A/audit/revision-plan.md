# 冻结解答修订计划

本文件只给证据化修订建议；本次 audit 未修改 frozen-solution。建议从新的可写修订副本执行以下顺序。

## P0：修复会改变 Q3 可行性与选型的事项

### 1. 参数化重物球几何并加入球流阻

- 将球的排水体积、等效水动力直径/投影面积、阻力作用点列入输入。
- 若使用实心钢球假设，由质量和密度计算直径；若不是实心球，禁止用材料密度代替整体排水体积。
- 在球节点写水平力平衡，避免把球流阻错误地重复传入钢桶力矩。
- 对 16–20 m、风 0–36 m/s、流 0–1.5 m/s 和压力裕量重新计算。

验收标准：

- 原 4800 kg 方案在含球流阻模型中的 5°、16°、吃水状态有明确 pass/fail。
- 新方案在声明的球几何范围和 10% 压力范围内均为 pass，或论文明确降级为 needs_review。
- 提供至少一个球节点水平力残差测试和一个手算投影面积案例。

### 2. 重建完整 Q3 设计搜索

- 对每种链型枚举搜索域中的每个整数链环数，禁止以 0.5 m 目标网格替代整数枚举。
- 把水下有效配重作为独立连续变量；为每个链方案保留完整的 draft-angle-radius 权衡，不只保留最小可行配重。
- 先构造完整可行集和 Pareto 前沿，再应用预先冻结的折中评分。
- 扩大链长和配重边界，直到入选设计和前沿对边界扩张、配重步长与链环枚举收敛。

验收标准：

- V-117/5050 kg 与 V-116/5200 kg 被纳入搜索或由明确硬约束排除。
- 入选方案分数不大于所有已枚举可行方案，并报告第二名及分数差。
- 网格/边界加密后入选设计稳定；若不稳定，状态为 needs_review。

## P1：修复可辨识性和复现证据

### 3. 用水下有效重量组织球参数

- Q2 主结论先报告连续水下有效质量约 1927.889 kg 或相应有效重量。
- Q1 对给定 1200 kg 至少报告排水体积参数式或多个合理密度情景。
- 所有干质量建议紧邻标注对应排水体积、密度和水动力直径。

验收标准：

- 不再出现未限定材质/体积的单一干质量结论。
- 改变球密度时，有效重量相同的静力结果在无球流阻工况下一致。

### 4. 使生成清单完全自包含

- 选择其一：让 solve.py 生成 results/README.md；或把 README 作为静态输入从 generated-manifest 中排除。
- 清单分开记录 source_inputs 和 generated_outputs。
- 在两个全新空目录运行，记录命令、环境、stdout、stderr、退出码、输出集合及逐文件 SHA-256。

验收标准：

- 两个空目录复跑的生成清单与发布清单逐字节一致。
- stdout 的 generated_files 与清单条目/清单自身计数定义一致。
- 文档不再声称静态输入是程序生成物。

## P2：文档与载荷身份改进

### 5. 修复 SVG

- 将 width="100%%" height="100%%" 改为 width="100%" height="100%"。
- 重新生成四个 SVG，并做严格语法检查和至少一次视觉渲染检查。

验收标准：SVG 检查为 pass，Markdown 图背景在浅色/深色宿主中均可读。

### 6. 声明 FROZEN 聚合哈希算法

- 在冻结 schema 中增加 tree_hash_algorithm、canonicalization_version、path_separator、encoding 和 ordering。
- 随 audit Skill 提供只读聚合校验器。

验收标准：独立环境可从 65 个清单条目复得 tree_sha256，状态为 pass。

### 7. 更新论文与结构化结果

- 所有 Q3 数字必须来自修复后的同一程序。
- 重新生成 candidate、Pareto、scenario、sensitivity、validation、TeX 宏、表格和图。
- 扩展一致性检查：按字段和语义位置核对，而不是只检查数字字符串是否在论文任意位置出现。

验收标准：

- 论文—代码—CSV/JSON/TeX 逐字段一致为 pass。
- LaTeX 实际编译和逐页视觉检查为 pass；无法执行时保留 needs_review。
- 冻结前重新生成 FROZEN 清单并在独立 audit 工作区验证。
