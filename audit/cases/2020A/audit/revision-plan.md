# 证据化修订计划

本计划只给出下一版本的修订顺序；本次 audit 不修改 blind-v1，也不跨阶段执行修订。

## P0：阻断性修订

### 1. 恢复题面 Q3 阴影面积

- 在新副本中定义 `q3_rising_area = ∫[t217_up,t_peak] (T-217) dt`。
- 对 217 ℃上穿时刻和连续峰值时刻插值；不要用离散 `argmax` 直接切片作为最终积分端点。
- 保留全段面积为诊断量，但不得再称为 Q3 目标。
- 验收：题面图 2、公式、代码、JSON、宏和论文中的 Q3 面积定义完全一致；独立 oracle 对解析三角/抛物曲线给出已知面积，状态 `pass`。

### 2. 重新定义 Q4 与 Q3 的结合方式

- 若保留 epsilon-constraint，面积上限必须基于修正后的 Q3 升温侧最小面积。
- 105% 属工程判断，应同时报告 100%、102.5%、105%、110% 的敏感性或 Pareto 前沿。
- 明确目标究竟是 `E_sym` 还是 `R_sym`；论文、代码和验收指标只保留一个主目标，另一个作为辅助量。
- 验收：所有 Q4 候选满足修正面积约束，且指标由独立实现复算为 `pass`。

### 3. 建立真正独立的数学 oracle

- oracle 不得导入 `core.curve_metrics`、`process_slacks`、`adjusted_slacks` 或 `solve.evaluate_design`。
- 从输出 `(t,T)` 独立计算首次交点、峰值、升降温斜率、两类面积、对称性和全部题面约束。
- 分开给出“RK45 时间积分一致性”和“题意/指标正确性”状态。
- 验收：人为把面积改回全段时，oracle 必须 `fail`；不能再次出现共同错误仍全绿。

### 4. 全量重算并新冻结

- 重算 Q3、Q4、敏感性、验证、图、宏、论文和结构化摘要。
- Q1/Q2 即使数字不变，也需重新跑完整回归，防止共享函数修改产生副作用。
- 生成新版本（例如 blind-v2），保留 blind-v1 作为不可变审计证据。
- 验收：新清单逐文件哈希和树哈希 `pass`；不得覆盖或伪装原冻结版本。

## P1：模型证据与稳健性

### 5. 处理残差相关与参数可辨识性

- 绘制残差时序/温度/位置图，报告 ACF、Durbin-Watson 和结构偏差。
- 用 GLS、相关误差模型或按时间块 bootstrap 重做候选比较；不要把 709 个稠密点直接当独立噪声。
- 对五个参数做 profile likelihood、联合置信域或可辨识性分析，重点检查 `lambda_down-k_cool` 与 `lambda_up-k_ref`。
- 验收：参数联合不确定性和模型差异被传播至 Q1-Q4，状态至少诚实标为 `needs_review`，不得用样本内 BIC 替代。

### 6. 区分数学最优与工程推荐

- 一套解严格使用题面原约束；数值容差应由网格/RK45误差界决定。
- 另一套可做工程稳健推荐，但安全裕度应来自参数、设定和速度联合不确定性，而非固定 0.1 ℃/0.2 s。
- 验收：两套解分别标注，原约束最优性和稳健可行性不混写。

### 7. 提升优化稳定性证据

- 对修正 Q3/Q4 至少运行 10 个种子，并使用一种不同的全局或约束优化方法复核。
- 对每次运行报告全局/局部退出状态、最终可行性、目标和设置分布；失败运行不得丢弃。
- 对 Q4 给出 epsilon/Pareto 敏感性，避免单个 105% 与单个种子决定结论。
- 验收：若无法证明全局最优，继续标 `needs_review`；局部稳定性只在所有验收运行可行且目标分散足够小时标 `pass`。

### 8. 增加外部实验

- 至少补一个不同速度和一个不同温区组合，最好覆盖升温与冷却参数的可辨识方向。
- 该数据在模型/阈值定稿前封存，仅用于外部评价。
- 验收：训练与外部评价来源分离；若无新实验，所有跨工况结论保持 `needs_review`。

## P2：论文与封存卫生

### 9. 修正元数据

- 最终封存后再生成 `solution-report.yaml`、`reproducibility.yaml` 和论文状态文字。
- 自动交叉校验论文 SHA-256、依赖、随机种子、知识卡清单和冻结状态。
- 锁定 `openpyxl==3.1.5` 或实际验证版本，并提供离线 wheelhouse/lockfile 以支持真正从空环境安装。
- 验收：不再出现 `not_frozen/未审计`、陈旧论文哈希、空依赖或空 seed 与实际代码冲突。

### 10. 编译和最终门禁

- 在有 XeLaTeX 的隔离环境编译论文，检查中文、公式、图路径和宏。
- 门禁顺序：阶段锁 `pass` → 输入身份 `pass` → 独立数学 oracle `pass` → 干净复现 `pass` → 论文编译 `pass` → 新冻结哈希 `pass`。
- 任何关键层为 `fail` 时禁止宣称整体正确；无法自动判定的外部有效性或全局最优性保留 `needs_review`。
