## 3. 参考后形成的 candidate 改进

### I1：道口约束的分层步行图

结构应为：

`外部设施 → 白色步行道路节点 → 合法道口商区 → 场馆环路 → 看台商区`

只允许题面或现场证据支持的边。若某处连接不清楚，不以欧氏最近自动补边，而是建立少量拓扑情景并分别求解。坐标抖动只处理边长，拓扑情景处理边的存在性。

- 相对当前比较集的新意：把参考论文的“道口商区”与 B 的不确定性传播结合。
- 预期收益：消除跨草地/跨车道直连；将结构误差与测量误差分开。
- 当前状态：`candidate`；尚未重算结果。

### I2：部分识别的配置前沿

将题面能识别的相对需求与不能识别的商业参数分开。输入集合至少包括捕获率、服务能力、上座率、固定成本和毛利；输出不是单点网点数，而是：

- 每个参数盒内的可行配置范围；
- 固定网点与可移动模块的两阶段方案；
- 满足供应、空间均衡和利润情景的 Pareto 前沿；
- 哪个现场量一旦测得最能缩小方案范围。

参考材料的 43、60/61、188、200 个结果说明单点方案对任意尺度参数高度敏感。

- 当前状态：`candidate`。

### I3：约束残差 + 小规模最优性证书

每次输出配置时同步生成：

1. 每条约束的逐区残差；
2. 总量与份额守恒；
3. 摘要、正文、表格的重复数值一致性；
4. 穷举、MILP gap=0 或可验证下界；
5. 若使用启发式，明确 best-known，不写“最优”。

R1、R3、R4 的具体错误都能被此模式捕获。B 已有部分检查，但尚缺“重解析论文公式并对最终解求值”。

- 当前状态：`candidate`。

### I4：关联变量的充分性筛选

先问“某属性是否改变当前输出所需的条件分布”：

- 若只有统一总体且各看台构成未知，行级 `P(交通, 餐饮, 消费)` 已足以计算聚合交易，无须把性别作为装饰性维度。
- 若获得各看台年龄/性别构成，则改用 `P(交通, 餐饮, 消费 | 人群, 看台)`。
- 对只与叙述有关、不能进入决策的相关性，报告但不硬塞进模型。

这是对 R2“规律要全面”和 B“不可识别协变量不外推”的综合。

- 当前状态：`candidate`。

## 4. candidate 验证路线

| 阶段 | 通过条件 | 失败条件 | 未具备证据 |
|---|---|---|---|
| 图拓扑单元测试 | 每条接入边能在题面白色通道或现场记录中定位 | 出现跨越非步行区域的直连 | 模糊道口的现场图，`needs_review` |
| 简化手算图 | 2—4 节点例与独立最短路一致 | 路径概率或曝光不守恒 | 无 |
| 参考表重算 | 能解释 R1/R3/R4 与 B 的差异来自哪些接入/平局规则 | 只能靠调参贴数 | 完整参考路线台账，`needs_review` |
| 配置证书 | 逐约束残差 pass，且穷举或 MILP 最优间隙为 0 | 仅报告求解器返回值或局部搜索 | 商业参数真实性，`needs_review` |
| 稳健性 | 数据、边长、拓扑、商业参数四层分别扰动 | 用坐标抖动代替拓扑错设 | 现场数据，`needs_review` |
| 外部有效性 | 现场 15 分钟流量、排队和销售数据校准后仍达服务指标 | 预演样本直接迁移失败 | 当前未提供，`needs_review` |

## 5. 不应宣称的创新

- 图论最短路、网络流、整数规划、灵敏度分析本身都不是本题内可宣称的新方法。
- “像素加权”若忽略合法步行边，不构成有效改进。
- 把多个既有元素拼接起来，只有在验证显示减少错误或提高决策收益时，才可描述为实用改进。
- 未经当前比较集之外的文献检索，不使用“首次”“首创”“国际领先”等措辞。
