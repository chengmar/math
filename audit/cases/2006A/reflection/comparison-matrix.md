# 冻结盲解与四篇参考材料对照矩阵

知识状态：`candidate`。

## 1. 对象

- **Blind**：最终冻结盲解《出版社书号资源的风险调整分层配置模型》。
- **R1**：《出版社的资源配置方案》。
- **R2**：《层次分析思想在出版社资源配置中的应用》。
- **R3**：《出版社的资源优化配置》。
- **R4**：《出版社资源配置的问题研究》。

## 4. 关键结论

1. **Blind 的优势主要来自证据链，而非模型名称更复杂。** 它是唯一给出简单基线、严格时间留出、统一约束复算、随机扰动不变量、代码生成结果和冻结哈希边界的对象。
2. **参考材料扩大了决策视角。** R1/R2 强调当前与长期效益，R3 显式加入年度变更平滑，R1 给出市场饱和解释；这些是 Blind 可以吸收的政策层补充。
3. **参考结果不能当标签。** 四篇中三篇主表有直接算术/约束 `fail`；R3 的选定方案可行，但稳定性表不保持固定预算。
4. **平方根凹收益与边际贪心是独立会合。** Blind 冻结前已使用 `eta=0.5` 的凹收益和离散边际求解；看 R4 后只能说在当前比较集中出现了独立趋同，不能把它记为参考后才学到，也不能宣称世界首创。
5. **Blind 仍不是数学真值。** 0.5 凹指数、风险折减、问卷小增益和利润代理都带工程判断；单个 2005 留出年不足以证明 2006 决策有效。
