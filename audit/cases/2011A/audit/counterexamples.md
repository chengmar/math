# 审计反例与压力测试

以下测试只使用允许目录中的题目附件、冻结代码和冻结结果。它们用于寻找失效条件，不是替代解答或外部真值。

## C1：共同背景扰动的排序稳健性是恒等式

状态：`fail`。

冻结区域指标为

\[
R_g=\left[\prod_{j=1}^8\frac{\operatorname{median}_{i\in g}C_{ij}}{B_j}\right]^{1/8}
=\frac{\left[\prod_j\operatorname{median}_{i\in g}C_{ij}\right]^{1/8}}
{\left(\prod_jB_j\right)^{1/8}}.
\]

只要每个功能区使用同一组正背景值，分母对所有区相同，所以任何共同的 `B_j` 扰动都不可能改变排序。500 个随机共同背景场只出现 1 种排序，不是额外证据。

若按假设 A1 真正担心的“背景空间变化”构造逻辑反例：工业区使用 `B+S`，交通区使用 `B-S`，其余区使用 `B`，均在报告采用的 ±1 SD 压力范围内，则指数变为：交通 2.461、工业 1.730、生活 1.715、公园 1.476、山区 1.003，交通反超工业。该场景不是背景真值估计，只证明原测试没有覆盖区域特异背景。

## C2：Pb 的非最大高值点推翻内部 pass

状态：`fail`。

冻结规则只删除每种元素的原始最大点。Pb 最大点删除后主峰不动，于是 Pb 被标为内部 `pass`。使用完全相同的 h=1 km 核面、0.45 敏感性阈值、最多 10 峰及最近峰匹配规则，改删第二高 Pb 样点 ID 6，主峰从 (1.00, 3.50) km 移动 3.691 km。该位移远超冻结内部阈值 1.5 km。

因此“删除最大点稳定”不能推出“对单点稳定”；影响最大者未必是原始浓度最大者。

附加支持诊断：Pb 峰 1 km 内无采样点，Gaussian 权重有效样本量约 7.41，前三个样点占核分子约 78.8%。

## C4：所谓经验程由大尺度趋势决定

状态：`fail`。

冻结代码把原始 log2 富集半方差首次达到全样本方差 95% 的箱中点作为经验程，得到 8.5–12.5 km。只对每个元素回归并去除二维线性坐标趋势，使用相同 1 km 分箱与阈值，结果变为：

| 元素 | 原始阈值穿越/km | 线性去趋势后/km |
|---|---:|---:|
| As | 8.5 | 2.5 |
| Cd | 10.5 | 1.5 |
| Cr | 12.5 | 2.5 |
| Cu | 11.5 | 2.5 |
| Hg | 10.5 | 1.5 |
| Ni | 11.5 | 3.5 |
| Pb | 11.5 | 1.5 |
| Zn | 11.5 | 1.5 |

这不是主张线性趋势模型正确，而是反例：未处理非平稳趋势时，该阈值不是稳健传播尺度。0–1 km 箱值也不是零距块金估计。

## C5：区域点 bootstrap 低估空间相关不确定性

状态：`needs_review`。

冻结 2000 次区内逐点重采样给工业区首位频率 91.75%。将同一 3 km 网格内样点作为一个簇，在每个功能区内进行 10000 次 cluster bootstrap，首位频率变为：工业 81.96%、交通 10.73%、生活 7.24%、公园 0.07%、山区 0%。

两种 bootstrap 都不是真值；差异证明逐点独立假设对排名概率有实质影响，应报告空间成组版本或区间。

## C6：未给初边值的 PDE 不唯一

状态：`fail`。

将论文后续方程简化为一维无源热方程

\[
\partial_t c=D\,\partial_{xx}c.
\]

在没有初值和边界条件时，常数场、不同 Fourier 模式及其组合都可满足方程；前向解不唯一，更不能反演源。即使补初边值，若 `K_epsilon` 不规范化，对任意 `a>0`，`q'=a q`、`K'=K/a` 给出相同源项，尺度仍不可辨识。未约束的加性 `eta` 还可使浓度为负。
