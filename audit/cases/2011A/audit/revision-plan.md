# 冻结解答证据化修订计划

本文件只提出新修订版本的建议；audit 阶段不修改 `frozen-solution`。

## P0：先恢复交付链一致性

状态：`fail`，优先级最高。

1. 在新的可写解答副本中完成正文修订后，再从空论文 build 目录连续编译两次。
2. 冻结同一次构建的 `main.tex`、生成表、图、`<SOURCE_FILE_REDACTED>` 和编译日志摘要。
3. 将一致性检查扩展为：生成表数值定位、TeX 引用、PDF 抽取文本与 TeX 语义摘要、页数和致命日志模式共同核对。
4. PDF 原始哈希可保留，但需另有去元数据/抽取文本哈希，避免把时间戳差异和内容差异混为一谈。

验收：空目录构建 exit 0；冻结 PDF 抽取文本与冻结源预期文本 `pass`；现有 8 处差异为 0。

## P1：重做 Q3 的传播与源区证据

状态：`fail`。

1. 删除或降级“西南—东北传播/拉伸”的结论，先加入固定采样设计的置换零模型；若需要方向，使用方向变异函数或显式各向异性协方差模型并给区间。
2. 把 `nugget_ratio_0_1_km` 改名为首箱经验半方差比；先处理趋势，再拟合合法变异函数，报告块金、基台、程的估计不确定性与分箱敏感性。
3. 对每种元素执行所有样点 leave-one-out、删除前 k 高值、空间块 bootstrap 和带宽/网格敏感性；记录峰消失、换序与位移分布。
4. 给核峰增加最低支持约束：有效样本量、1 km/2 km 邻点数、最大单点贡献、边界距离；报告候选区域或置信椭圆，不只报 0.25 km 网格坐标。
5. 立即把 Pb 的内部位置状态改为 `needs_review`，并优先复采 Cu/Hg/Pb/Ni 的稀疏或敏感热点。

验收：方向结论通过预设零模型或保持 `needs_review`；Pb 删除 ID 6 的 3.69 km 反例被覆盖；每个 pass 峰满足预设支持和影响阈值。

## P2：修正区域稳健性与背景不确定性

状态：`fail`。

1. 删除“共同背景 ±1 SD 导致排序 100% 不变”作为稳健证据的表述，说明该排序对共同背景是代数不变量。
2. 若取得背景点原始数据，建立含母质/空间位置的背景层级场；将区域特异背景后验传播到 `R_g` 和超越率。
3. 现阶段至少使用 3 km 空间块 bootstrap 或 cluster jackknife，报告排名频率、工业—交通差值区间和翻转概率；把 i.i.d. 结果只列为敏感性对照。
4. 说明 `R_g` 是“各元素区域中位数的几何平均”，不是同一个“典型点”的八元素几何富集；可并列代码已计算的 `median_site_geometric_enrichment`。

验收：不再把恒等不变量标作验证 pass；空间成组不确定性进入主表；背景空间变化保持 `needs_review` 直至有数据。

## P3：修复 NMF 训练—评价分离

状态：`fail`，当前结论影响较小。

1. 每个 CV 训练折单独估计 RMS 尺度，再转换验证折；最终全数据尺度仅用于最终拟合。
2. 将缩放、NMF、分量匹配封装为显式 pipeline，并保存每折尺度、迭代状态和误差。
3. 除 `nndsvdar` 小扰动外，加入更广的初始化/算法敏感性；把高余弦解释限定为数值局部稳定，不升级为真实源唯一。

验收：无验证数据参与预处理；修正后表格与代码一致；若仍选 k=3，按新数值更新全文。

## P4：补全后续 PDE 的适定性、量纲和可辨识性

状态：`fail`。

1. 定义空间—深度域 `Omega`、时间区间、初始浓度场、地表/底部/侧边界的通量或浓度条件。
2. 用守恒通量形式明确对流项；规定 `D_j` 对称正定/半正定、`lambda_j>=0`、`q_jk>=0`、`c_j>=0`。
3. 规定 `K_epsilon` 的三维归一化及单位，使 `qK` 与 `partial c/partial t` 同量纲；定义过程噪声和测量噪声单位。
4. 采用 log/正值状态或非负随机过程，避免加性噪声产生负浓度。
5. 在反演前做结构可辨识性与实际可辨识性分析；固定无法由数据区分的参数，设计时间、深度、源端指纹和边界通量采样。

验收：给定参数、初边值时前向问题唯一且保持非负；所有方程量纲闭合；`q` 与核尺度可分；模拟恢复实验能报告覆盖率。
