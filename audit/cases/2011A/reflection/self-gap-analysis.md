# 2011A 自身差距分析

知识状态：`candidate`
对象：`blind-v1`、独立审计、最终冻结盲解、4 篇批准参考材料

## 1. 时间顺序

1. `blind-v1` 在未读参考材料时独立完成。
2. 独立审计完整执行，冻结完整性和数值复现为 `pass`，但整体审计因 6 项 major 问题为 `fail`。
3. Blind Revision 根据审计生成最终版本；外部调度器随后生成并验证 `FROZEN_BLIND_FINAL.json` 与 `REFLECTION-BOUNDARY.json`。
4. 本阶段在权威冻结哈希全部 `pass` 后，才读取参考材料。

因此，最终版本中的内容不能一概称为“独立初始想到”：需要明确区分初始独立内容、审计修订内容和参考后认识。

## 4. 查看参考后才暴露或补足的部分 `[R]`

### 4.1 缺少经典污染指数的沟通基线

最终盲解选择了稳健几何富集指数，避免未经核准的外部等级和极值支配。这在证据上合理，但竞赛读者熟悉单因子/内梅罗指数。参考后重实现显示：

- 用背景均值 `B`：五区内梅罗为 3.171、13.533、1.253、9.426、2.734；
- 用 `B+2SD`：变为 2.090、9.277、0.824、6.463、1.869。

相对排序不变，绝对等级明显变化。未来可增加“标准依赖的辅助基线表”，同时并列稳健主指标、起点定义、pH/土地用途适用条件和敏感性。当前批准材料本身不能证明标准适用性，故该建议为 `candidate`，规范状态 `needs_review`。

### 4.2 对机理候选的显式枚举不足

盲解正确拒绝在单期数据上拟合不可识别 PDE，但参考材料提醒了三类可检验假设：道路的线源距离衰减、水/土/气多介质通量、类定位模型。可取之处不是它们现有坐标，而是把未来采样设计写成模型判别问题：

- 比较欧氏距离、道路/河网网络距离和下风/下游距离；
- 用重复时间与深度剖面识别传输方向；
- 用源端指纹和排放时间序列区分相邻源。

这些内容属于看参考后形成的候选研究设计，不属于独立盲解成果。

### 4.3 简明导航还可改善

参考论文常在摘要或表格中直接映射“四问—方法—结果”。盲解摘要数字充分，但技术状态多、读者负荷高。未来表达可增加一页导航表：每问只列主模型、主数值、证据状态、最关键限制；正文再展开验证。此为表达 `candidate`，不复制任何参考论文语言或章节结构。

4. `candidate`：在不替换稳健主指标的前提下，加入经过适用性审查的经典污染指数辅助表。
