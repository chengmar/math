# 2011A 相对创新与实用增益分析

知识状态：`candidate`
“创新”范围：仅相对当前冻结盲解与 4 篇批准参考材料，不涉及文献检索，不宣称世界首创。

## 1. 相对当前比较集的主要增益

### 1.1 从“画出表面”升级为“验证后制图” `[I]`

四篇参考主要直接采用 Surfer、二次/三次插值或 `griddata v4`。盲解先以空间常数为基线，再在相同空间块上比较 IDW 与 Gaussian，并将带宽选择限制在外层训练数据内。最终还加入连续区域及 1/2 km 缓冲留出 `[A]`。

实用增益：能回答坐标信息是否真正改善留出误差，并把 2 km 限定为制图超参数。相对创新状态 `pass`；跨城市有效性 `needs_review`。

### 1.2 区域污染从确定性均值改为空间成组不确定性 `[I+A]`

盲解用分元素中位数降低长尾极值支配，再跨元素取几何平均 `[I]`；审计后将 i.i.d. 点 bootstrap 改为空间块 bootstrap，并报告工业—交通翻转概率和差值区间 `[A]`。参考材料的内梅罗表更直观，却大多只给确定性等级。

实用增益：既保留区域顺序，又显示前两名并非绝对分离。计算状态 `pass`；背景空间变化下的顺序 `needs_review`。

### 1.3 把共变模式与源身份分层 `[I]`

参考材料多用 PCA 载荷直接命名交通、工业或生活来源；其中两篇 PCA 只有 5 个功能区观测。盲解用 319 点的非负共变分解，并明确统计分量不等于物理源谱。

实用增益：非负载荷更容易作混合模式说明，同时避免把聚合相关写成具体排放因果。折内预处理是审计后修复 `[A]`。数值状态 `pass`；源谱唯一性 `needs_review`。

### 1.4 让采样几何成为方向主张的零模型 `[A]`

初始盲解也曾把椭圆方向写得过强。审计后固定 319 个坐标，仅置换富集值，检验观察到的方向是否超过采样设计本身；0/8 通过，因而撤回方向主张。

实用增益：这是“能否不说”的验证，而不是为得到显著结果而追加复杂模型。相对当前参考集有明显证据优势，检验执行 `pass`；真实传播方向 `needs_review`。

### 1.5 用反例驱动热点降级 `[A]`

参考材料通常给单一源坐标。最终盲解对所有 319 点做 LOO、累计删除前三高值、带宽/网格扰动、最低支持和空间块重采样。Pb 删除第二高值 ID 6 后移动 3.691 km，促使八个精确中心统一降为 `needs_review`。

实用增益：结果不是“更多坐标”，而是明确哪些坐标只适合作为复采区域。影响诊断执行 `pass`；排放源定位 `needs_review`。

### 1.6 把动态方程改成条件完整的未来模型 `[I+A]`

初始盲解已经认识到单期数据不宜拟合动态逆问题 `[I]`；审计后补齐三维域、时间、初边值、守恒通量、核归一化、量纲、正定/非负约束和可辨识性计划 `[A]`。参考材料的水/土/气、Gaussian、Geiger 方程提供了机理方向，但大多缺参数标定和边界。

实用增益：把“写出 PDE”改成“说明何时才有资格反演”。规格完整性 `pass`；实际逆问题 `needs_review`。

## 2. 参考材料带来的新候选 `[R]`

### 2.1 双起点污染指数敏感性

本地重实现确认：以 `B` 和 `B+2SD` 为起点评价值，内梅罗绝对数值和等级改变，但五区相对顺序保持。该对照可作为未来论文的辅助沟通层：

- 主结果保留稳健、少外部假设的区中位几何指标；
- 辅助表报告经典指数及起点敏感性；
- 明确标准版本、pH/用途适用条件和极值支配。

数值对照 `pass`；规范解释 `needs_review`；知识状态 `candidate`。

### 2.2 把线源/网络源写成可判别假设

REF-C 的线源衰减和多篇道路叙述提醒：未来不应只比较欧氏核热点，还可比较“到道路/铁路/河网的网络距离、下风距离、下游距离”。当前材料没有完整道路/河网与时间数据，不能反推现有源；候选设计状态 `needs_review`。

### 2.3 以机理模块反推采样变量

水/土/气三介质与类定位模型虽未在参考中被充分标定，但可转化为数据需求：风、雨、流量、颗粒沉降、含水率、吸附参数、源排放时间和深度剖面。其价值在采样设计，不在现有坐标结论。知识状态 `candidate`。

### 2.4 一页式交付导航

参考材料的摘要通常快速覆盖四问。盲解可进一步压缩为“问题—主模型—关键数值—证据状态—关键限制”一页表，再保留高强度验证细节。该表达建议为 `candidate`。

## 3. 看似复杂但不构成可靠创新的内容

| 内容 | 原因 | 判断 |
|---|---|---|
| 未标定的三介质 PDE 叠加后直接读源区 | 方程参数、初边值、目标函数和不确定性不完整 | `needs_review` |
| 用浓度差替代到时差的 Geiger 类定位 | 缺少浓度—距离/时间的可识别映射 | `needs_review` |
| 五区 PCA 后直接命名污染源 | 只有 5 个聚合观测，秩至多 4，且混杂严重 | `needs_review` |
| 多篇论文给出同一区域顺序 | 同一数据与相似单调指标，不是独立外部验证 | `needs_review` |
| NMF 高余弦稳定 | 只说明已检验算法邻域的数值稳定，不证明物理源唯一 | `needs_review` |
| 可复现哈希 | 证明实现一致，不证明数学正确或物理因果 | `pass` / `needs_review` 分层 |

## 4. 相对收益—成本

| 方案 | 计算成本 | 解释门槛 | 证据收益 | 适用建议 |
|---|---:|---:|---|---|
| 区均值 + 内梅罗 | 低 | 低 | 快速排序与等级，但极值和标准敏感 | 作为辅助基线 `candidate` |
| 五区 PCA | 低 | 中 | 当前样本层级不足，源解释弱 | 不作主来源模型 |
| 直接插值图 | 中 | 低 | 视觉强，泛化误差未知 | 需配空间留出 |
| 盲解空间验证栈 | 高 | 中高 | 模型选型、翻转概率、方向反例、热点脆弱性可量化 | 当前主方案 |
| 动态多介质反演 | 很高 | 高 | 在新增时间/深度/输运/源端数据后潜力大 | 当前只保留条件模型 |

## 5. 不应推广的“经验”

- 不把“工业 > 交通 > …”推广为其他城市规律。
- 不把本题 1/2/3 km 带宽或 3 km 分块推广为固定超参数。
- 不把 Hg、As–Cr–Ni、Cd–Cu–Pb–Zn 标签推广为通用源谱。
- 不把内梅罗阈值或 `B+2SD` 起点视为无条件适用标准。
- 不把某篇材料中的具体坐标、扩散系数、衰减系数或毒性权重迁移到新题。
- 不把“更多方程”当作“更强证据”。

## 6. 结论

相对当前比较集，最终盲解的核心增益不是更激进的源结论，而是更可靠地界定哪些结论不能由当前数据支持。最值得形成 `candidate` 的方法是空间成组验证、采样几何零模型、全影响热点诊断和条件适定的后续模型；最值得从参考吸收的是经典指数的沟通层与机理驱动的采样设计，而不是其未复现的源坐标。
