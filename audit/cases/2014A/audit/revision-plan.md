# 2014A 冻结解答证据化修订计划

本文件只给修订建议，不修改冻结解答。建议从 `frozen-solution` 派生新版本，保留 blind-v1 不变，并在新版本上重新执行 solve→verify→freeze→audit。

## P0：先修正会改变可行性或题目覆盖的核心问题

### 1. 统一绝对高度、DEM 高程与离地净空

对应发现：AUD-2014A-002。

建议改动：

- 明确名义月面、粗图中心、粗选点、精图中心和精选点的垂直基准及转换；若附件不能提供绝对配准，建立显式条件假设并把状态标为 needs_review。
- 动力学状态使用月心距或统一绝对高度；另计算 `clearance(t)=absolute_height-terrain(x(t),y(t))`。
- 将 100 m、30 m、4 m 解释为对相应地形点的净空，而不是固定平面坐标中的绝对 `h`。
- 对粗/精横移路径做连续地形净空与碰撞检查，重新计算 5% 推力裕度、燃料和关机自由落体。

验收标准：

- 每个阶段边界同时报告绝对高度、当地地形高程和净空，三者关系可复算。
- 轨迹全程 `clearance>=0` 为 pass；30 m、4 m 净空在数值容差内为 pass。
- 4 m 自由落体高度直接来自所选点净空，而不是硬编码或未配准 DEM 值。
- 在所采用配准下重新检查 `1500--7500 N` 与设计裕度；不能确认配准时相关结论为 needs_review。

### 2. 把开环参考升级为可验证的闭环控制策略

对应发现：AUD-2014A-001、AUD-2014A-003。

建议改动：

- 给出状态估计输入、误差状态、反馈/制导律、阶段切换逻辑和在线重规划触发条件。
- 将姿态角、角速度和主发动机方向纳入状态；加入姿态角速度/角加速度、推力转向速率、节流速率、最短保持时间和延迟约束。
- 让段间至少满足推力矢量连续，删除近 180° 的瞬时翻转；必要时增加有限时长姿态过渡段。
- 在全程连续仿真中注入质量、推力、方向、导航噪声和延迟，不在阶段边界无条件重置到名义状态。

验收标准：

- 代码中存在明确可执行的反馈/重规划实现，而不只是“需要闭环”的文字。
- 推力幅值、方向、幅值变化率和姿态变化率全部按连续时间认证为 pass。
- 扰动仿真报告落点误差、速度误差、燃料和约束失败率；未给真实执行器界限时为 needs_review，不得自动 pass。
- `solution-report.yaml` 只有在闭环证据通过后才把 Q2 的 control coverage 标为 pass。

### 3. 重写独立验证器，消除自报 pass

对应发现：AUD-2014A-004。

建议改动：

- `verify.py` 从轨迹和推力原始数值重新积分，并由验证器自己应用位置、速度、质量阈值；忽略 CSV 中已有的 `status`。
- 对 stage boundaries、参数敏感性和 DEM 阈值也重新计算，不信任结果文件中的派生状态。
- 将输入清单锚定到只读 FROZEN 清单或外部签名；验证器不得通过修改同目录 manifest 来为篡改结果重新背书。
- 论文构建必须实际执行 XeLaTeX/latexmk，记录命令、日志、退出码和输出哈希；检查 PDF 头、页数和构建新鲜度。
- 把 CE-01 加入回归测试：百万米误差和伪 PDF 必须使验证器 fail。

验收标准：

- CE-01 的两个伪造场景均得到 fail，退出码非 0。
- 正常 clean run 由独立重算得到 pass，且日志能定位所有公式、阈值和输入文件。
- 删除“非空文件即编译成功”的逻辑。

## P1：修正最优性、连续约束和 DEM 方法表述

### 4. 联合优化全部耦合变量并降低最优性表述强度

对应发现：AUD-2014A-005、AUD-2014A-009。

建议改动：

- 对主减速下程、五段时间和两个自由下降速度进行联合优化，避免三个顺序子块造成质量—推力约束耦合遗漏。
- 使用多起点、多随机种子和至少一种不同算法交叉检查；保留冻结方案和本审计反例作为基线种子。
- 优化后用自适应极值搜索或解析包络认证连续时间推力，不仅检查 121 点。
- 分开报告 problem bounds、design margin 和 optimisation target，给出明确数值容差。

验收标准：

- 新方案燃料不高于本审计的同 5% 裕度反例 `1172.868910 kg`，或给出可复核的反例不可行原因。
- 联合搜索的多起点结果、最优值跨度、活跃约束和停止准则完整记录。
- 只有在有下界/最优性间隙证据时才使用“最优”；否则写“可行近优解”或“搜索所得最好解”。
- 连续时间题定约束和设计裕度均为 pass；内部目标若仍越界则如实 fail。

### 5. 统一 DEM 足迹几何和验证范围

对应发现：AUD-2014A-007、AUD-2014A-008。

建议改动：

- 在圆盘半径和方窗半宽之间选择一个明确物理定义；代码、公式、图形和文字使用同一几何。
- 若采用圆盘，使用圆盘卷积/掩膜并按圆盘边界设置图像 margin；重新生成行列号、指标、敏感性和图。
- 将现有检查改称“选择后内部阈值检查”，不要称为数据独立验证。
- 同时报告冻结名义点在半径、权重、量化和配准扰动下的指标；不要只报告每次重新选出的最优点。
- 若能取得独立 DEM 或测量误差模型，再增加真正的留出/噪声验证；否则外部安全保持 needs_review。

验收标准：

- 论文的 Omega、图中足迹和代码像素集合完全一致。
- 圆/方简化反例的行为与所选定义一致，且不再存在隐藏的 30% 面积差。
- 内部 pass 与外部 needs_review 的证据层级在报告中清晰分离。

## P2：修复冻结、复现和构建 provenance

### 6. 原子生成冻结元数据和可复算树哈希

对应发现：AUD-2014A-006、AUD-2014A-010。

建议改动：

- 在最后一次求解、重复性比较、论文编译和验证完成后，一次性生成 `reproducibility.yaml`、`verification.json`、`solution-report.yaml` 和 FROZEN 清单。
- FROZEN 清单写入实际 seed、命令、依赖、知识卡和 clean/dirty 状态；统一两个 retrieval log。
- 让声明命令完整再生权威载荷，或将人工/后处理步骤写成有命令、有哈希的正式 build stage。
- 定义 `tree_hash_algorithm`、`canonicalization_version`、路径排序、分隔符和编码；提供只读校验工具。
- 冻结后将 paper/report 中的阶段状态改为 frozen，并确保验证结果与快照内 PDF/重复性文件一致。

验收标准：

- 从全新目录执行一条文档化 build 命令后，全部权威载荷逐字节匹配新 FROZEN 清单。
- FROZEN、reproducibility、solution report、verification 和 retrieval logs 的 seed、命令、依赖、知识卡、冻结和编译状态一致。
- 第三方仅按清单定义即可复算 tree SHA-256；结果为 pass。

## 建议的重新验收顺序

1. 从 blind-v1 派生新工作副本，保留旧冻结版不变。
2. 实现 P0 的地形坐标、闭环/执行器和独立验证器。
3. 执行 P1 联合优化、连续约束认证和 DEM 重算。
4. 在多个种子与扰动下执行 solve 和真正独立 verify。
5. 实际编译论文，核对宏、图、表和结构化结果。
6. 按 P2 原子生成 provenance 与 FROZEN 清单。
7. 在新的只读冻结快照上重新调用 `$cumcm-a-audit`；任何未给物理参数的外部结论继续标为 needs_review。
