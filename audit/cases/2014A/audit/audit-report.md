# 2014A 冻结解答独立审计报告

## 审计结论

总体状态：**fail**。

冻结完整性和数值复现本身通过：阶段锁有效，路径清单哈希一致，FROZEN 清单中的 90 个文件均逐文件匹配大小与 SHA-256；三次全新目录复跑（其中一次使用 Python `-I -B` 隔离模式）均以退出码 0 完成，声明输出清单哈希完全一致，两次普通复跑的 39 个文件树逐字节相同。轨道活力公式、位置/速度几何、火箭方程质量连续性和跨阶段连续重积分也通过独立复核。

但“可复现”不等于“解答正确”。本审计发现 5 项 major、4 项 minor、1 项 suggestion：没有实现题目所需的闭环控制策略；DEM 高程没有进入垂直轨迹和 4 m 自由落体；参考控制包含近 180° 的瞬时推力翻转；验证器可对百万米重积分误差和伪 PDF 给出 pass；并且同一有限维模型中存在更省燃料、仍满足 5% 推力裕度的联合优化反例。因此，`solution-report.yaml` 对 Q2 的 pass 和论文的“函数空间内数值最优”不能保留。

`FROZEN_BLIND_V1.json` 声明 90 个文件。本审计逐项检查路径不能逃逸冻结根目录、文件存在、字节数和 SHA-256：90/90 通过；必需载荷无缺失，未发现清单外文件，也没有清单声明排除的 `__pycache__`、`.aux`、`.log`、`.out` 构建残留。工作区 `input` 与冻结快照 `input` 的 5 个源文件记录完全相同。

## 干净复现

使用冻结脚本指定的运行时：Python 3.12.13、NumPy 2.3.5、Pillow 12.3.0，平台 `Windows-11-10.0.26200-SP0`。首次 PATH 中没有 `python` 命令；按 `run_all.ps1` 的固定运行时路径找到解释器后，原 Skill 阶段检查和求解命令均成功。

三次复现摘要：

1. `audit-clean-run-1`：solve 17.642 s、verify 0.149 s；退出码均 0，stderr 为空。
2. `audit-clean-run-2`：solve 17.649 s、verify 0.133 s；退出码均 0，stderr 为空。
3. `audit-clean-run-isolated`：以 `-I -B` 运行，solve 17.668 s、verify 0.143 s；退出码均 0，stderr 为空。

三次求解 stdout 都给出燃料 `1173.5792695044317 kg`、4 m 质量 `1226.4207304955683 kg`、动力时间 `572.7827397245292 s`，且重积分自报 pass。两次普通 clean run 的 39 个文件树逐字节一致；隔离 run 与其也逐字节一致。冻结快照的 21 个核心产物中 20 个与新生成文件逐字节一致，唯一不一致的是 `reproducibility.yaml`：冻结版多了 `repeatability_evidence`，而 `solve.py` 不会生成该字段。

详细命令、stdout、stderr、退出码和环境见 `reproduction-report.json`。

## 数学、量纲与数值检查

通过项：

- 重新计算 `mu=GM=4.904075411e12 m^3/s^2`，与结果一致。
- vis-viva 给出近月点 `1694.05575239148 m/s`、远月点 `1615.55764025650 m/s`，与报告逐位一致。
- 近/远月点位置向量模长等于对应半径，速度向量模长等于报告速度，位置与速度正交。
- 五段报告的总 `delta-v=1973.824229035124 m/s`，与 `2940*ln(2400/1226.4207304955683)` 的差约 `6.8e-13 m/s`；段间质量连续。
- 0.02 s 推力扫描下，题定 `1500--7500 N` 和设计 `1575--7125 N` 均 pass；七个参数扰动在同样密网格下仍 pass。
- 不在阶段边界重置名义状态的单次链式 RK4 最终位置、速度、质量误差分别约 `1.18e-4 m`、`1.44e-6 m/s`、`4.16e-6 kg`，名义动力学数值稳定。
- 5 个差异很大的优化随机种子均收敛到几乎相同结果，燃料跨度仅约 `7.49e-6 kg`。

失败或需复核项：

- 121 点优化网格不能保证连续时间约束；0.02 s 扫描显示内部目标轻微越界到 `1599.767964--7100.070317 N`。题定约束仍 pass，故为 minor。
- 三个顺序子块不构成 8 变量联合最优。联合搜索在同一 5% 验收区间得到更少燃料方案，且密网格与 RK4 复核均 pass。
- 每段只约束位置、速度连续；推力方向和幅值在边界不连续，其中一次近 180° 翻转。
- DEM 高程没有进入绝对高度/净空方程；因此地形碰撞、30/4 m 相对地面边界和自由落体速度没有被同一坐标系验证。

## 泄漏、过拟合与验证独立性

没有观察到联网检索当前题目、读取参考论文或访问禁区的证据。冻结目录只包含三张通用的早年训练记忆卡，内容是验证工作流，不是本题现成解答；但 `FROZEN_BLIND_V1.json` 写 `knowledge_cards=[]`，另一个 retrieval log 写 `cards=[]`，而 `reports/training-memory-retrieval.json` 列出三张卡，故 provenance 只能 needs_review，不能声称绝对证明无历史泄漏。

DEM 的“独立硬阈值”不是真正的数据独立验证：综合分数和硬检查使用同一张图、同一组三个指标，只是聚合方式不同；扰动测试还会为每种设置重新选点。固定冻结点在 3--7 m 方窗下仍全部 pass，这支持内部稳定性，但不能消除选择后偏差或替代外部地形验证。
