# 2009A 相对创新与实用增益分析

## 1. 判断边界

“创新”只相对 BF 与 R1–R4 这个当前比较集判断，不宣称世界首创、竞赛首创或文献首创。参考论文没有默认正确性；没有经过复现的想法只能作为 candidate。

## 2. 不是本轮创新的内容

| 内容 | 比较集证据 | 判断 |
|---|---|---|
| 平动能—转动惯量等效 | BF 与 R1–R4 全部出现 | 非创新，属于共同物理基础 |
| 三飞轮 30/60/120 与 +12/−18 补偿 | BF 与 R1–R4 全部出现 | 非创新 |
| 电流与制动扭矩成比例的前馈控制 | BF 与 R1、R3、R4 出现 | 非创新 |
| 用上一时段扭矩控制下一时段 | BF、R3、R4 明确出现 | 非创新；BF 的独立性由冻结时间线支持，但不等于文献新颖 |
| 用反馈或预测减小时延 | BF、R1、R3、R4 均有不同版本 | 方向本身非创新 |
| GM、BP、模糊 PID、粒子群或多目标规划 | R2–R4 出现 | 算法名称不是创新证据；本题中多项还缺执行细节 |
| 用能量相对误差评价控制器 | 所有材料均使用 | 非创新 |

## 3. 相对当前比较集的实用增益

### 3.1 有界预测、观测、约束与停止的一体化

BF 的最终 Q6 同时包含：

- 两个历史斜率的 minmod 非负预测；
- L=0.25 的状态观测校正；
- 不随 1/h 放大的固定 K=500 速度反馈；
- 低扭矩零命令、等效惯量、绝对扭矩和变化率投影；
- 过零插值、非负速度和停止锁存；
- 声明步长/实际惯量域。

R1–R4 没有任何一篇同时覆盖这些部件。相对比较集，这是一个“把可执行边界补齐”的集成增益，而不是单个控制理论组件的原创。模型内约束和反例证据为 pass；真实硬件收益为 needs_review。

### 3.2 反例驱动而不只看名义能量误差

BF 用低扭矩、速度噪声、40/300 N·m 快速交替、18/78 kg·m²、恒扭矩停止和扭矩标定偏差挑战控制器。R3 有初值与阶数表，R4 有随机场景，但四篇参考都没有检查低扭矩病态比值、反转停止和命令安全集合。

相对比较集，BF 的增益是把“名义误差小”改成“名义误差 + 约束 + 反例 + 失效条件”。该验证模式具有可推广价值，提案状态仍为 candidate。

### 3.3 冻结证据与唯一生成链

BF 记录输入原始字节、规范化语义、逐产物来源、source/PDF freshness、确切环境与 170 项外部冻结哈希。R1–R4 只有 PDF，且都没有批准范围内的代码。

这不是数学模型创新，但对结果可信度和可复查性有明显实用增益。必须说明该链条来自审计后修正，不应归功于盲解初稿。

### 3.4 求积假设与公式一致

BF 最终使用“扭矩和转速分别线性”下的分段精确乘积积分。R1–R4 使用不同矩形、端点或不明规则。精确积分只把结果从端点功率梯形修正 0.018854 J，工程结论不变。

因此这是数值一致性改进，不应包装成重大创新。价值在于揭示 Q4 数字差异常来自口径而不是模型优劣。

### 3.5 状态词和证据边界

BF 把数值计算、工程接受、硬件可行性、物理验证分别标为 pass 或 needs_review。R2/R4 自定“优/良/差”阈值，R3 对 N→∞ 的表述较强。

相对比较集，BF 的实用增益是避免把“论文算出数字”升级为“工程合格”。这是表达与治理改进，不是算法原创。

## 4. 参考后学到、但尚不能认定为增益的候选

| candidate | 来源 | 潜在收益 | 主要风险 | 当前判断 |
|---|---|---|---|---|
| 显式时移算子与因果时序图 | R3 | 让一拍滞后、索引和预测目标更易审查 | 连续 Laplace 表达可能掩盖采样、噪声与饱和 | needs_review |
| 预测阶数—误差—运行时曲线 | R3 | 把计算预算纳入模型选择 | 高阶差分放大噪声；无源码复现 | needs_review |
| K、L 或反馈系数扫描 | R3 启发 | 比单点参数更能展示稳定/性能取舍 | 需要预声明评价集，避免在同一轨迹调参和评估 | needs_review |
| 多类扭矩场景族 | R4 | 增加步长、初速、周期与随机扰动覆盖 | 若由同一轨迹拟合并回测，会形成封闭验证 | needs_review |
| 神经网络/PID 作为替代控制 | R2、R4 | 可能处理未建模非线性 | 参数、训练集、硬件约束和实时性缺失；当前证据不足 | needs_review |
| 多目标规划/粒子群离线分配 | R3 | 可把能量、跟踪和电流同时纳入 | 可能非因果；论文声称可行域凸，但模型含非线性余弦，论证不足 | needs_review |

## 5. 不应推广或不应宣称的内容

- 不应把 Q1–Q3 的共同教科书关系宣称为新颖。
- 不应因为 BF 的名义 Q6 误差最小，就认定它优于 R3/R4；仿真环境并不相同。
- 不应把 R3 的 N→∞ 理论极限直接转成工程零误差。高阶差分、噪声、Taylor 收敛、饱和和延迟都可能破坏结论。
- 不应把 R2 的 GM/BP/PID 方法名称当成已实现模型；缺关键参数即为 needs_review。
- 不应把 R4 的 0.1%/1% 等级阈值迁移到其他设备、步长或题目；它没有题面或硬件验收依据。
- 不应把 PDF 版面完整、参考文献丰富或软件名称众多当作数学正确性证据。
- 不应把软件设置的 281.25 A、187.5 N·m、9375 N·m/s 当作真实电机额定值。
- 未做额外文献检索，因此不作世界首创、行业领先或文献空白声明。

## 6. 结论

BF 相对 R1–R4 的主要贡献是“有界、可停止、可反例检验、可追溯”的完整工程闭环，而不是提出了前人没有的扭矩前馈或预测思想。其模型内实用收益有证据，硬件与物理收益仍为 needs_review。R3 的时延与运行时表达、R4 的场景族意识可形成下一轮 candidate，但必须重新实现、固定验证协议并与调参数据隔离。
