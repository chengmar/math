# 证据化修订计划

本计划只提出下一版修订要求；本次 audit 未修改冻结解答。

## P0：重新建立可信输入与唯一生成链

1. 修复原始附件处理（对应 `AUD-001`）。
   - 在 Excel 启动前计算当前 `input` 原件哈希。
   - 只对独立临时副本做 COM 解析；原件在解析前后必须保持同一哈希。
   - 同时记录原始字节哈希、解析后副本哈希和规范化数值表哈希。
   - 验收：原件 pre/post SHA-256 相同为 `pass`；否则 `fail`。

2. 合并为一条权威管线（对应 `AUD-002`）。
   - 明确选择 `solve.py` 或 `analyze.py`，不能让两套 `pass` 结果并存。
   - 从空输出目录运行唯一命令；所有保留的结果、图、表、PDF 都必须由该命令生成。
   - 删除或迁移未被 `main.tex` 引用的旧章节、旧图和 `paper/build` 副本。
   - 验收：冻结生成物集合与 clean run 生成物集合完全相等为 `pass`。

3. 重建论文并重新冻结（对应 `AUD-003`）。
   - 清除 `.aux/.out/.log/.pdf` 后双遍编译。
   - 验证器比较 `main.tex`、全部 `\input` 源、生成宏与 PDF 文本/书签。
   - 重新生成 `verification.json`，再创建 FROZEN 清单。
   - 验收：冻结 PDF 含 `main.tex` 的全部章节，验证报告记录哈希等于冻结实际哈希为 `pass`。

## P0：补齐控制器硬约束

4. 修复低扭矩限幅（对应 `AUD-004`）。
   - 当 \(|\widehat M|>\varepsilon\) 时严格执行 \(|J_eu/\widehat M|\le30\)。
   - 当 \(|\widehat M|\le\varepsilon\) 时切换到绝对电流/扭矩/变化率限制，不再用惯量比值。
   - 添加逐时段 constraint assertion。
   - 验收：包含 \(\widehat M=0,0.1,1\) N·m 的单元测试全部 `pass`。

5. 加入停止与可行状态逻辑（对应 `AUD-006`）。
   - 定义末速/零速事件、过零插值、\(\omega\ge0\)、结束后电流平滑归零。
   - 到达停止事件后不再累计制动能量或传播反向转速。
   - 验收：20 s 恒扭矩反例不会出现负转速；若越界则自动 `fail`。

## P1：给 Q6 一个可证明的适用域

6. 重设计速度校正（对应 `AUD-005`）。
   - 明确推导 \(|1-\gamma J_d/J_a|<1\) 的稳定域，并按允许惯量范围选择 \(\gamma\)。
   - 使用速度滤波或状态观测器，量化 \(J_m/h\) 对测量噪声的电流增益。
   - 增加绝对电流、扭矩、变化率、抗饱和和传感器故障降级到 Q5 的逻辑。
   - 对扭矩预测加入非负/斜率约束或稳健预测器。
   - 验收：速度噪声、快速扭矩、宽惯量区间和饱和测试均有预先声明的 `pass` 阈值；硬件阈值未给时维持 `needs_review`。

7. 扩展验证集并避免“同轨迹即稳健”的表述。
   - 名义附表只作为一个模型内案例；另用常扭矩、阶跃、跌落、交替、低扭矩和停止案例。
   - 若没有独立物理轨迹，明确写成 model-in-the-loop，不称实机稳健性验证。
   - 验收：每个反例有命令、输入、输出、阈值和状态，且失败能使总验证状态变为 `fail`。

## P1：加强独立验证

8. 让 verifier 检查性质而不只复写公式。
   - 独立检查因果索引、状态约束、补偿限幅、稳定域和 PDF/source freshness。
   - 禁止仅以文件存在、文件大小或 Markdown 数字 token 作为一致性充分条件。
   - 验收：人为恢复旧 PDF、低扭矩限幅反例或负转速反例时，验证器均返回非零退出码和 `fail`。

## P2：数值与环境收尾

9. 统一积分假设（对应 `AUD-008`）。
   - 若 \(M\) 与 \(\omega\) 分别线性，采用精确乘积积分；若采用功率线性，则改写假设。
   - 验收：论文公式、代码和报告尾数一致为 `pass`。

10. 清理冻结环境元数据（对应 `AUD-007`）。
    - 从 clean git 状态构建，排除 `__pycache__`。
    - 填写 Python 包、PowerShell、Excel 与 XeLaTeX 版本；固定 CSV/JSON 编码和换行。
    - 对 PDF 区分“内容可复现”和“字节可复现”。
    - 验收：FROZEN 目录除清单自身外没有未列文件，依赖不为空，跨声明环境的目标复现级别均为 `pass`。
