## 4. 综合比较结论

1. **模型结构**：BF 在接触参考前已独立建立与 R3/R4 同类的“地区×性别×年龄”队列框架；这是独立想到，不是参考后复制。R4 的年龄迁移模式更细，BF 的主迁移率则更保守、可辨识但过于平坦。
2. **结果可信度**：BF 的复现、滚动留出、内部不变量和联合敏感性证据最完整；但抽样设计、尺度锚和附件老龄冲突仍使科学状态为 `needs_review`。
3. **参考优势**：R3 的模型递进和 R4 的状态空间/指标体系更适合教学表达；R2 展示了短期标量模型与结构模型的多时间尺度视角。
4. **参考风险**：R2 出现 Logistic 参数回代失败，R4 出现表文数字冲突；R3 的异常因果归因没有证据。参考材料必须经过定义、算术、代码和留出四层检查。
5. **复杂度权衡**：BF 的计算阶数与 R3/R4 同为状态规模线性，但验证工程更重；其收益是能明确区分“程序跑通”“内部守恒”和“科学可用”。

比较集总体判断：`needs_review`。没有材料足以把本题经验直接升级为 `verified`。
