# 冻结盲解自我差距分析

> 知识状态：`candidate`。本分析以冻结时间线为边界，不把参考材料中的观点倒灌为“盲解原本就想到”。

## 1. 来源归属账本

### 1.1 独立想到（Blind V1 阶段已存在）

以下内容在读取批准参考材料之前已经出现在盲解证据链中：

- 用投影矩进行几何初始化，再在投影域联合细化中心、间距、起始方向和增益。
- 明确区分射线方向、探测器法向和数据列顺序，并用同一前向投影器检查标定残差。
- 同时保留 FBP 基线与非负 SIRT 主重建，不只提交一张视觉图。
- 用已知模板做像素误差、投影误差和十点结果检查。
- 提出非对称/可辨识性更强的新标定模板，并用模拟与敏感性分析评价。
- 以参数表、假设表、证据层和复现目录组织答案。

这些属于**独立思路**，但其正确性不能因“独立”自动成为 pass。

### 1.3 看参考后学到（本 reflection 才产生）

- R2/R3 的连续圆弦解析模型在 85 个独立列上极稳定地给出 `d≈0.276754`，促使把**物理探测器间距**与 B 的**离散算子有效间距**分开描述。
- R3 的平方弦长二次关系提供了比投影矩更直接的物理解读，可作为联合优化的外部解析约束，而不是直接替换联合优化。
- R3 对不同对象采用/拒绝 Wiener 的频谱理由说明：模板上选出的滤波器不能无条件迁移到复杂对象。
- 四篇材料对附件 5 十点值的分歧远大于 B 的迭代敏感性，暴露了此前未充分报告的**跨算法结构不确定性**。
- R3 的相位互补双椭圆设计与 B 的非对称模板思路可以组合成多方向、多频率的条件数设计准则。
- R1/R4 的支撑区间虽粗，却适合用作联合优化的物理可行域审计护栏。

这些只能标记为**参考后学习的 candidate**，不得追溯性写成盲解原创。

## 3. 主要差距与优先级

### G1：物理参数与离散算子参数混同（最高优先级）

- **现象**：解析圆弦方法稳定给出 `d≈0.276754`，而 B 为 0.275617，相差约 0.001137 mm（约 0.41%）。
- **风险**：若 B 的 `d` 吸收了像素驱动插值、有限探测器宽度、PSF 或中心偏差，它就不应直接解释成仪器物理间距。
- **改进 candidate**：固定解析物理 `d`，另引入条带宽度/PSF/亚像素偏置；与当前自由 `d` 模型做嵌套比较和留出验证。
- **当前判断**：`needs_review`。不能用参考值覆盖冻结值。

### G2：附件 5 的结构性不确定性低估

- **现象**：四个参考结果与 B 的十点 RMSE 为 0.147–0.486，而附件 3 仅 0.010–0.019。
- **风险**：只报告同一 SIRT 家族的迭代敏感性，会遗漏滤波器、几何和重建先验之间的模型选择差异。
- **改进 candidate**：建立预注册的 FBP/SIRT/带正则模型集合；报告点值的算法包络、模型加权结果和各自投影残差，不把包络当真值置信区间。
- **当前判断**：`needs_review`。

### G3：问题三的物理量定义仍不闭环

- **现象**：B 的孔隙率随阈值 0.4–0.6 为 0.2694–0.2947，孔数 92–94；阈值与材料相、PSF 和噪声之间没有独立标定。
- **风险**：视觉上稳定不等于物理分类阈值正确，孔洞连通性也会受分辨率影响。
- **改进 candidate**：从已知模板边缘扩散估计 PSF，做分辨率校正后的多阈值拓扑持久性；若无物理标签，只报告操作性定义。
- **当前判断**：`needs_review`。

### G4：探测器响应模型过于理想化

- **现象**：B 使用像素点到相邻探测器的线性分配，未显式建模有限探测器条带积分、焦斑宽度或响应核。
- **风险**：几何和增益可能补偿算子误差，导致参数解释偏移。
- **改进 candidate**：比较点采样、矩形条带积分、高斯 PSF 三种前向模型；同样进行折内重拟合和复杂度惩罚。
- **当前判断**：`needs_review`。

### G5：固定 1° 角步长虽更稳健，但缺少正则化对照

- **现象**：R3/R4 允许逐角变化；R3 的逐角表相对固定 1° 只改善约 1.81e-5 NRMSE，R4 还出现 3.473° 跳步。
- **风险**：完全固定可能遗漏真实机械误差，完全自由又易过拟合。
- **改进 candidate**：估计 `θ_j=θ_0+jΔ+u_j`，对 `u_j` 加二阶平滑或周期约束；以留出误差和有效自由度选惩罚。
- **当前判断**：`needs_review`。

### G6：滤波/正则化跨对象迁移缺少外部验证

- **现象**：B 主要用同一迭代框架；R3 提醒附件 3 和附件 5 的频谱不同，R4 则从模板选择 Wiener 后迁移。
- **风险**：模板最优的平滑强度可能压低复杂对象的高频真实结构。
- **改进 candidate**：预先按投影残差、频谱保真和边缘保持三指标选模型；模板调参后在不参与选择的合成对象族上验证迁移。
- **当前判断**：`needs_review`。

### G7：噪声模型虽经审计改进，仍不代表仪器噪声

- **现象**：完整估计器共同高斯扰动优于 Blind V1，但没有重复扫描来识别异方差、相关噪声和系统漂移。
- **风险**：稳定性 CI 只对选定的模拟噪声分布有效。
- **改进 candidate**：明确写成“条件模拟稳定性”；若将来获得重复标定，估计均值—方差关系和列相关后再替换噪声模型。
- **当前判断**：现有模拟执行 `pass`，外部代表性 `needs_review`。

### G8：计算代价披露不够便于方法选择

- **现象**：B 的 SIRT80 和 120 对全流程复算比多数参考方案昂贵，但报告主要强调统计改进，没有统一列出墙钟时间、内存和精度收益。
- **改进 candidate**：给出每阶段复杂度、单次/全稳定性运行时间和 NRMSE—时间 Pareto 曲线。
- **当前判断**：`needs_review`。

### G9：交付层仍有非数学缺口

- **现象**：严格原始输入文件身份检查为 `fail`，最终论文编译状态为 `needs_review`；虽然数值身份和清洁复现已通过，但不能混称完整交付通过。
- **改进 candidate**：把“数值身份”“字节身份”“论文编译”“结果哈希”分别列状态，不用一个总 pass 覆盖。
- **当前判断**：保持原状态，不升级。

## 4. 不应采取的“修正”

1. 不把 `d` 直接改成 R2/R3 的 0.2768；先证明估计对象相同。
2. 不用四篇论文的中位数替代缺失真值；参考方法共享假设且并不独立。
3. 不把 Blind Revision 的方向、泄漏和噪声修正写成“看论文后改进”；时间线表明它们来自 Audit。
4. 不因 B 的共同算子 NRMSE 最低就宣布物理参数正确；模型错配也可由自由参数吸收。
5. 不把附件 5 的方法间离散称为统计置信区间；它只是结构不确定性诊断。
6. 不覆盖冻结文件或回写盲解历史。

## 5. 建议的下一轮候选验证顺序

1. 解析物理 `d` + 响应核的嵌套模型；折内重拟合并比较留出 NRMSE、参数稳定性和有效自由度。
2. 固定角、平滑角、逐角自由三模型的预注册对照。
3. FBP/SIRT/正则模型集合对附件 5 十点和拓扑指标的算法包络。
4. 频谱分层的合成对象族，检验模板调参向复杂对象迁移。
5. 最后才讨论是否形成更高等级知识；本阶段全部保持 `candidate`。
