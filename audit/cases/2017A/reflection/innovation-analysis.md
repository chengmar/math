## 2. 最有价值的候选：双尺度标定

### 核心思想

把参数写成两层：

1. `d_phys`：由已知圆弦几何约束的物理探测器间距；
2. `d_eff` 或响应核参数：描述有限条带、PSF、像素插值和亚像素偏置对当前离散算子的等效影响。

当前 `d_phys≈0.276754` 与 `d_eff≈0.275617` 的差异不应被隐藏在一个参数中。候选模型可固定 `d_phys`，把响应核宽度、探测器偏置或积分条带作为新增但受约束的参数，再用无泄漏留出比较。

### 为什么它有价值

- 保留 R2/R3 的解析可解释性；
- 保留 B 的投影域拟合能力；
- 能检验 B 的低 NRMSE是否来自合理响应模型，还是几何参数代偿；
- 对其他“物理模型 + 离散实现”问题也可迁移。

### 为什么还不是 verified

- 目前没有仪器探测器宽度、PSF 或重复扫描真值；
- 解析圆弦拟合也会受阈值、物体非理想圆和探测器积分影响；
- 新模型尚未进行嵌套比较、外折验证和参数可辨识性分析。

因此状态为 `needs_review` / `candidate`。

## 3. 验证创新：比单一最好分数更重要

B 相对参考材料最可靠的增量，不是“某个结果最接近”，而是以下验证结构：

- 验证折内重新估计参数，避免初始化泄漏；
- 共同噪声下比较完整估计器，减少不必要的蒙特卡洛方差；
- 把模板像素误差、投影残差、点值、拓扑量和复现状态分层；
- 对方向取模、探测器行反转、阈值和停止准则保留可审计反例；
- 冻结证据由外部调度器生成，并由本阶段再次核对 436/436 哈希。

这些模式具有通用性，但不能掩盖噪声分布和前向算子仍是人为选择的事实。

## 4. 模板设计候选

四篇材料中的新模板大多停留在理论图形：R1 的方形/六边形，R2 的方形/圆，R3 的相位互补双椭圆，R4 的四带组合。B 已独立提出非对称模板并做模拟。更可迁移的候选准则不是继续枚举形状，而是：

1. **非对称性**：消除 180°、镜像和行反转等方向歧义；
2. **相位互补**：不同主轴角度对角度误差保持互补灵敏度；
3. **多尺度/多频率**：同时识别中心、间距、PSF 和增益；
4. **支撑分离**：保证不同基元在足够多角度下可单独提取；
5. **条件数目标**：用参数 Jacobian、Fisher 信息最小特征值或最坏方向方差评价，而非仅看重建图是否“清楚”；
6. **制造约束**：最小孔径、材料动态范围和托盘边界作为硬约束。

该组合设计来自独立模板思路与 R3 启发的混合，必须明确标注来源，状态为 `needs_review` / `candidate`。

## 5. 复杂度—收益判断

| 方法族 | 主要代价 | 观察到的收益 | 候选结论 |
|---|---|---|---|
| B 联合标定 + SIRT80 | 多参数优化、80 次迭代、120 对全流程复算 | 最低共同投影 NRMSE，验证证据最完整 | 值得保留，但应报告时间/内存 Pareto，`needs_review` |
| R1 几何 + FBP | 代价低 | 直观、中心接近 B；投影同尺残差较高 | 适合作审计基线，不宜作唯一主模型 |
| R2 逐角 1e-4 搜索 | 约 180×20,000 级候选评估，再加滤波搜索 | 共同算子近似 NRMSE 接近 B，但完整角表缺失 | 性价比和误差传播 `needs_review` |
| R3 解析拟合 + 逐角表 | 中等 | `d` 可解释性强；逐角自由度对 NRMSE 收益约 1.81e-5 | 保留解析 `d`，角扰动需正则化 |
| R4 方程 + 滤波比较 | 中高 | 模板内滤波误差有对照 | 角表和跨对象滤波迁移 `needs_review` |

## 6. 不构成创新的内容

- FBP、SIRT、Wiener、R-L 滤波等已有算法本身；
- “用已知模板标定未知 CT”这一题设内基本思路；
- 取可行区间中点、肉眼选角或仅报告更小训练残差；
- 把参考论文结果取平均或多数投票；
- 把审计修复重新包装成最初盲解就具备的创新；
- 没有实机数据的新模板图形本身。

## 7. 建议使用的表述边界

可以说：

- “在冻结数据和共同离散前向算子下，候选方法的投影 NRMSE 更低。”
- “解析圆弦估计与离散算子联合估计之间存在可重复差异，提示参数语义可能不同。”
- “跨算法结果离散提示结构不确定性尚未覆盖。”

不应说：

- “证明了 B 的参数最准确。”
- “四篇参考验证了最终答案。”
- “新模板已经优于所有方案。”
- “结果已升级为 verified。”
