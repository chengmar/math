# 冻结解答证据化修订计划

本文件只提出后续修订建议；audit 阶段未修改冻结解答。

## P0：修正角度语义与方向表

1. 将用于 $s=d(k-255.5)$ 的探测器坐标有向法向角输出为不取模序列 `29.6741+(j-1)`°。
2. 另列无向 X 射线直线角（可模 180°）和无法由吸收投影决定的源到探测器符号。
3. 若坚持法向角模 180°，为每列增加 `reverse_detector_index`，跨界后使用 `k -> 511-k`。
4. 用发布的方向文件重新驱动正投影；180 列 NRMSE 应与内部模型一致。

验收：发布方向重新正投影 NRMSE 与内部不取模模型差小于数值舍入误差，状态 `pass`；否则 `fail`。

## P0：重做无泄漏的角步长选择

1. 在划分后，仅用训练角重新拟合矩初始化、中心、间距、起角、步长和增益。
2. 使用保留原角索引的拟合设计，避免把抽样后的角误当连续角。
3. 采用多个连续角块或重复分块验证，最终保留一块完全未触碰的数据。
4. 报告每折参数、训练/验证误差、均值和离散度；若固定/自由步长差异落入折间波动，则标为 `needs_review`，不得强判。

验收：验证数据在所有拟合与超参数选择完成前不可访问，自动检查状态 `pass`。

## P0：重做第 (4) 问稳定性实验

1. 明确噪声是全探测器加性高斯、信号相关、泊松或截断模型；实现必须与文字完全一致。
2. 每个复现先生成完整 512×180 噪声张量，再对新旧模板复用相同张量；不得按模板非零支撑跳过随机数。
3. 每次复现运行最终完整标定器，包括矩初始化、投影域优化和增益，而非只跑 `FitUniform`。
4. 保存复现级参数，报告偏差、标准差、协方差、分位数和失败率。
5. 对标准差降幅给置信区间或跨种子稳定范围，不把 200 次模拟的比例解释到四位有效小数。

验收：噪声经验均值/方差和支撑独立性测试 `pass`；完整估计器复现 `pass`；新模板改进区间若跨 0，则结论为 `needs_review`。

## P1：给 SIRT 建立停止/正则化准则

1. 输出 0、5、10、20、40、80、160 等迭代的模板真值误差、投影残差、噪声放大和未知样品十点变化。
2. 用独立模板/验证角、差异原则、L 曲线或预先规定的误差阈值选停止点。
3. 将迭代数作为不确定性来源，报告十点值和几何量随合理停止区间的范围。

验收：停止规则在查看未知样品最终值前冻结，状态 `pass`；若只能依赖工程判断，标 `needs_review`。

## P1：量化附件 5 几何分割不确定性

1. 给出阈值选择依据、连通规则和最小孔尺寸的物理意义。
2. 报告阈值 0.4--0.6 等合理区间内的面积、孔隙率、孔数和最大孔范围。
3. 将“封闭孔隙率”改称“给定重建与阈值下的封闭孔隙率”，除非有独立分割标定。

验收：主要几何结论附敏感性区间，状态 `pass`；物理孔隙率仍无真值时保持 `needs_review`。
