## 1. 来源分层

### 1.1 冻结前独立想到

下列内容已存在于外部冻结清单覆盖的盲解中，因此归为“独立想到”，不因后来在参考论文中见到相似概念而改写来源：

1. 一般透视下，物圆圆心像不等于像椭圆几何中心。
2. 五个已知等圆共享同一平面单应，圆锥曲线满足 `Q_i ~ H^{-T} C_i H^{-1}`。
3. 用全部亚像素边界联合估计，而不是把每个圆压缩成一个人工中心点。
4. 同时比较自由单应和已知焦距位姿，并用整圆留一误差控制复杂度。
5. 通过 `R21=R2 R1^T`、`t21=t2-R21 t1` 消去靶标坐标系；靶标毫米尺寸提供平移尺度。
6. 阈值敏感性、固定种子轮廓扰动、极端输入拒绝和明确失效条件。

这些内容的来源证据是冻结版 `paper/paper.md`、`model-selection.md`、`results/` 和 `code/`，不是本次参考阅读。

### 1.3 看参考后才学到

下列内容在冻结盲解中不存在，必须标为参考后学习：

1. 等圆外公切线的两条切点弦可给出圆心像，适合做与圆锥联合模型异质的几何交叉检查（R0D、R2F）。
2. 内公切线交点—两圆心共线可构造全图约束，但纯行列式方程含全相等伪解族，必须增加非退化约束（R62 及本次重实现）。
3. 用交比或构造点检查射影一致性，适合作为说明性诊断，但不能替代独立真值（R0D）。
4. 对相机—靶标距离和两个倾角做网格扫描，可以把“适用条件”从文字变成相图（R2F）。
5. 特征点数量与多起点求解敏感性应显式展示，不只报告一次收敛结果（R203、R62）。

这些内容只进入 `candidate` 提案，不倒写进“盲解独立创新”。

## 3. 对参考材料的反向校正

参考论文不是答案库，以下内容不能照搬：

- R0D 的整数切点不能重算出正文中心表，最大差 4.16 px；其 `O(n)` 复杂度声明也未覆盖边界点配对。
- R203 所印“旋转矩阵”正交性为 `fail`，且焦距反求被预先限制在 ±2%，不能支持“误差小于 2%”的独立结论。
- R2F 的椭圆系数算术可复现，但常深度假设使它得到的是近似椭圆中心；高 `R²` 不等于物圆心像正确。
- R62 的十个共线方程存在连续全相等伪解族；论文展示坏初值是有价值的，但还没有从结构上消除退化。
- 多篇论文的双相机公式存在最少点数、平移符号或尺度说明问题，不能默认优于冻结盲解。

## 4. 下一步候选改进

1. 实现公切线圆心估计器，只作为独立交叉检查；用共享单应模型与切线模型差异形成模型不确定性区间。状态：`candidate`。
2. 在合成真值上扫描距离、两个倾角、主点偏移、焦距误差和径向畸变，报告失败相图而不是单一阈值。状态：`candidate`。
3. 对非线性拟合做多起点、边界稀疏化和损失尺度敏感性；显式拒绝退化解。状态：`candidate`。
4. 获得至少一组第二相机同步图像与独立内参后，实测 `R21,t21` 并做跨姿态一致性检查。状态：`candidate`。
5. 在同一机器上比较圆锥联合、逐圆椭圆和公切线法的时间、内存、误差与失败率。状态：`candidate`。

上述改进均未写入冻结历史，也未改变当前盲解结果。
