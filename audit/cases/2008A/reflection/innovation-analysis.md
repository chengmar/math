## 2. 参考后形成的组合候选

以下组合在冻结前不存在，必须标明为“看参考后学到”：

### 2.1 圆锥联合估计 + 公切线异质交叉检查

公切线构造与完整边界圆锥拟合使用不同的信息压缩和误差路径。把二者的圆心差作为模型不确定性诊断，比用两个共享同一参数化的优化器互相验证更有价值。

- 优点：几何解释强，可暴露分割、标号或内参假设偏差。
- 必须增加：亚像素切线、平行/近平行条件数、切点不确定性传播、退化解过滤。
- 不能声称：参考论文的公切线数值就是真值。
- 状态：`candidate`。

### 2.2 真实图组留出 + 合成姿态相图

冻结盲解的整圆留一检验真实图像内外推；R2F 的距离—倾角扫描检验模型适用域。二者组合能区分“当前图像拟合”与“几何条件失效”。

- 建议扫描：距离、两个倾角、主点偏移、焦距误差、径向畸变、遮挡比例和边缘噪声。
- 输出应是失败相图与覆盖率，而不是只给一个平均误差。
- 状态：`candidate`。

### 2.3 可辨识性先验门 + 多起点数值门

R62 表明多起点能发现坏根，但本次重实现进一步发现全相等连续伪解族。以后应先做代数/几何可辨识性检查，再做多起点；仅凭多个初值收敛一致不能证明唯一性。

- 状态：`candidate`。

## 3. 不构成创新声明的内容

以下概念本身在多份材料中重复出现，且未做外部文献检索，不能作为首创：

- 针孔成像、平面单应和相机内外参；
- 射影保持共线、交比和切触关系；
- 用 SVD/最小二乘求姿态或对应点矩阵；
- 蒙特卡洛噪声、阈值敏感性和多起点求解；
- 用靶标分别标定两相机后组合旋转和平移。

可讨论的只是这些组件在本题中的组合方式、验证强度和工程可追溯性。

## 5. 结论

当前比较集内最有实用价值的独立贡献，是“共享圆锥边界 + 整圆留出选型 + 可复现证据链”的组合。最值得从参考材料吸收的新候选，是“公切线异质交叉检查 + 姿态适用域相图 + 可辨识性前置门”。它们均保持 `candidate`，没有进入核心知识或改写冻结盲解历史。
