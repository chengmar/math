# 自身差距分析

## 1. 结论

最终冻结盲解在质量守恒、喷嘴结构不确定性、执行器约束、事件收敛和复现证据上整体强于当前三篇比较材料，但仍为 `needs_review`。最重要的新缺口不是“把答案调到参考数值”，而是给集总压力假设增加传播时间尺度门槛；其次是补齐周期泄压架构基线、目标权重稳健性和计算复杂度报告。

## 2. 来源分层

### 独立想到（参考导入前已存在于 `blind-v1`）

- 由 \(E(P)\) 数值积分恢复 \(\rho(P)\)，建立柱塞腔—油管耦合 ODE。
- 以周期平均模型作低复杂度基线，并用动态模型报告均值、RMSE、峰峰值。
- 针阀瓶颈面积主模型之外，已实现串联阻力结构敏感性，发现约 16.3% 的角速度差异。
- 比较 0、25、50 ms 两喷嘴相位，独立得到 50 ms 错峰。
- 区分经济方案和高稳压回流方案，并报告回流/喷油比。
- 有时间步、参数扰动、设计/评价窗口分离和重跑哈希意识。

这些内容出现在参考材料开放之前。与 R-A、R-B 的 0.2875/0.288 ms、与三篇的约 0.0272–0.0275 rad/ms 以及 50 ms 错峰相近，属于独立收敛，不是看参考后补写。

### 审计后修正（仍在参考导入前）

- 把不同高压侧定义的体积流量先转成质量流，修正问题 1 的核心答案。
- 用精确周期质量平衡替代体积平衡搜索中心，并增加物理质量残差回归。
- 把喷嘴两结构从“敏感性”提升为答案区间，而不是给唯一瓶颈点值。
- 公开初始凸轮相位，延长预热并做四相位集合评价。
- 给减压阀加入开关延迟、分别最小驻留和滚动切换上限，按六种能力情景重优化。
- 修复跨目录复现、来源台账和未执行安全规则等证据问题。

### 看参考后才学到或被参考触发

1. **泄压控制架构应先分型再调参。** R-B、R-C 都把压力触发泄压与周期脉冲泄压分开比较。最终盲解只优化了回差触发族，缺少定时泄压这一结构基线。该学习项只生成 candidate，不接受其论文数值。
2. **均匀压力假设必须过传播时间尺度门槛。** R-C 提到了空间传播但论证不成立；按题给数据复算的理想单程时间约 0.313 ms，大于 0.2 ms 喷油上升段，暴露了最终盲解未量化的模型风险。
3. **主文应给可执行控制律。** R-A 把 2/5/10 s 的时变开阀规则直接写成分段公式，尽管其数值有误差；最终盲解给出了通式和代表点，但完整逐周期表藏在 CSV。更好的表达是主文同时给通式、边界、切换规则和机器表位置。

## 3. 分维度差距

| 维度 | 最终盲解现状 | 与参考比较后的差距 | 优先级 | 判定 |
|---|---|---|---|---|
| 模型边界 | 集总定容、均匀压力 | 未用传播时间与最短激励时间比较；当前比值不支持无条件忽略波动 | P0 | `needs_review` |
| 泄压架构 | 回差触发 + 延迟/驻留/切换约束 | 缺周期定时泄压和混合前馈/反馈架构的同口径基线 | P1 | `needs_review` |
| 优化目标 | RMSE + 回流量权重 + 切换权重 | 权重 0.0005、0.002 未归一化，也未给 Pareto 或权重敏感性 | P1 | `needs_review` |
| 结构不确定性 | 两个喷嘴端点区间 | 端点不一定包络真实双节流，因为两处流量系数可能不同 | P1 | `needs_review` |
| 事件收敛 | 问题 2 事件次数未收敛 | 仍不能从离散事件数反推真实单向阀带宽 | P1 | `needs_review` |
| 外部有效性 | 明确为模型内 | 没有台架压力、流量、阀时序或中间压力 | P1 | `needs_review` |
| 复杂度 | 代码可重跑、结果有哈希 | 没有逐阶段耗时、状态步数、网格规模和内存摘要 | P2 | `needs_review` |
| 表达 | 结论、区间和证据边界清楚 | 完整过渡控制需跳到 CSV；条件方案的选择门槛可再压缩成决策表 | P2 | `needs_review` |

## 4. 不能从参考材料学的内容

- 不学习 R-A 的单位混写和“结果较精确”式无阈值自评。
- 不学习 R-B 在缺执行约束时用极高泵速换取压力稳定的做法。
- 不学习 R-C 的常比例本构、500 mm/50 m 混淆及摘要—正文数量级冲突。
- 不把三篇都使用瓶颈面积视为该结构已经被验证。
- 不用“多篇结果接近”替代质量残差、收敛、结构识别或外部实验。

## 5. 后续 candidate 验收建议

1. 用一维可压缩管流模型或特征线法复算至少一个喷油周期；比较管端和管中压力峰值，决定集总模型能否保留。
2. 在同一执行器约束和同一成本尺度下，比较回差触发、定时脉冲、前馈+反馈三种泄压架构。
3. 将压力误差、回流量、切换次数无量纲化，给出 Pareto 前沿或至少三组权重敏感性。
4. 记录每个阶段的模拟时长、时间步、状态更新数、候选数和墙钟时间。
5. 在正文给出完整可执行控制规则；CSV 只承载高分辨率明细。

以上均保持 `candidate`，未经新证据不得升级为 verified。
