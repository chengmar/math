# 自身差距与来源分层

## 三类来源边界

| 类别 | 内容 | 证据边界 |
| --- | --- | --- |
| 独立想到 | 用截面弓形面积沿轴积分；用相邻流量守恒识别角度；比较无变位、仅纵倾、两角模型；认识 beta 符号不可辨识；生成罐容表并做数值加密 | 已存在于冻结 V1 或其审计记录；形成时未读取参考材料 |
| 审计后修正 | 分离选择与检验数据；小罐增加姿态尺度+零点候选；修正球冠半径公式；建立单一产物链与 PowerShell 7 复现命令；接入独立自适应积分；增加 HAC、累计状态目标、流量比例/几何/零点压力场景；正文按 1 L 报告 | 来自独立 audit 的 findings 与 blind-revision 响应；仍发生在参考读取前 |
| 看参考后才学到 | 参数差异可能很大而最终表差很小；静压力导致罐壁变形可作为后续工程扩展；无量纲接口可改善跨尺寸复用；八类显式分段可被裁剪截面函数替代作为复杂度反例；参考复现应拆成“文件—文本—代码—数值—数学”层级 | 只在本次读取 R1–R4 并完成交叉计算后形成，不能回写成盲解原创 |

## 与参考集相比的优势

### 模型与算法

最终盲解的半径剖面 `r(x)` 和有符号截高 `u(x,h)` 把圆柱、球冠、空/满边界放在同一积分中，不需要 R3 的八类情形，也避免 R1/R4 对球冠的端点液位或拆补近似。其优势是接口统一、边界可自动裁剪、独立积分器易于重实现。

### 验证

参考材料大多把样本内拟合、旧显示表一致性或小数很小的相对指标称作正确性。最终盲解在审计后明确了数据角色，并加入时间块检查、独立积分、解析容量、单调/边界、累计状态目标、HAC 和工程压力场景；验证层次明显更完整。

### 结论边界

最终盲解把实际表称为固定流量比例、固定几何和固定零点条件下的点表，并明确压力范围不是置信区间。参考集常把相对误差小直接推到“正确可靠”。最终盲解的表达更符合证据强度。

## 参考对自身结果的压力

1. R4 的实际罐表与最终盲解只有 14.23 L 节点 RMSE，但 beta 相差 0.346°。这支持“表函数可能比 beta 更稳定”，也暴露了当前论文仍以角度为中心的表达偏好。
2. R1 的表系统性高约 138 L，提示球冠/横偏几何近似会造成输出偏移；不能用“多篇角度接近”替代几何复核。
3. 多篇参考的小罐名义模型在倾斜进油上有 77.62 L RMSE。最终盲解对测量机理的修正有实证收益，但其物理解释仍未闭合。
4. R2 提到静压力形变，这是最终盲解压力场景尚未覆盖的一类因素；题目缺少壁厚、弹性模量和密度，当前只能作为扩展清单，不能加入数值区间。

## 不应回写的事后知识

- 不把 R1/R2/R4 的角度区间写成盲解阶段的先验。
- 不把 R4 与盲解表接近写成独立验证真值。
- 不把参考论文的奖项、篇幅或拟合系数当成正确性证据。
- 不把读取参考后形成的“参数—功能输出双轨验证”说成初始盲解原创。
- 不为贴近参考表而修改冻结盲解、参数、表值或审计历史。
