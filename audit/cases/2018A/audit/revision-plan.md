# 冻结解证据化修订计划

本计划只给出下一版本的修订建议；当前 `frozen-solution` 不作任何修改。整体优先级状态为 `needs_review`。

## P0：先确定工程判据

1. 明确初始条件与使用协议。
   - 指定服装是否在 37℃预平衡、常温存放或可能预热。
   - 给出四层初温/初始温度场的允许范围，而不只引用皮肤首值。
   - 验收：推荐厚度在全部授权初值下满足两项安全约束，状态 `pass`；否则保留 `needs_review`。

2. 明确 Q3 的优化目标。
   - 由使用方给出总厚度、质量、材料成本、空气隙体积和舒适性的权重；若无法给出，报告可行 Pareto 前沿。
   - 对 (d_2+w d_4) 至少给出若干权重敏感性，解释为何选择最终组合。
   - 验收：目标有题意或工程依据，或结论改为“在所选目标下的条件最优”，状态 `pass`。

## P1：解决会改变厚度答案的模型不确定性

3. 扩展 IV 层候选结构。
   - 至少比较纯导热、导热加并联等效热导、温度相关等效换热三种结构。
   - 不允许只凭同一个 (d_4=5) mm 工况的时间留出选择厚度迁移规律。
   - 优先补充多个 (d_4) 与 65/75/80℃组合的独立测温实验；同时记录层间或表面温度以提高可辨识性。
   - 验收：不同可接受结构给出的推荐厚度一致到制造分辨率，状态 `pass`；否则输出情景范围并标 `needs_review`。

4. 把名义优化升级为稳健约束优化。
   - 基于测量量化、相关残差、重复实验、物性公差和边界系数迁移误差定义不确定集合。
   - 分开报告参数估计不确定性、模型结构不确定性和制造公差，不把任意 ±5% 当作统计置信区间。
   - 在该集合上求最坏情形或规定置信水平的 (T_s(t_f)) 与 (D_{44})。
   - 验收：所有授权情景均满足 (T_s\le47)℃、(D_{44}\le300) s，状态 `pass`；否则主推荐不得使用“确保”。

5. 增加辨识与残差诊断。
   - 保留现有多起点测试，并加入剖面似然或参数置信区域。
   - 对残差自相关和 0.01℃量化建立观测模型；当前 lag-1 相关约 0.665，不应按逐秒独立样本计算窄置信区间。
   - 验收：参数/预测区间的构造假设有诊断支撑，状态为 `pass` 或明确 `needs_review`。

## P2：修复数据与复现链

6. 让附件 1 成为模型的真实输入。
   - 从工作簿构建材料对象并传入求解器；或在计算前逐项断言工作簿值与代码常量完全一致。
   - 删除只读后展示、计算时另用硬编码常量的双源设计。
   - 验收：任一材料字段不一致会在建模前 `fail`，当前输入一致时 `pass`。

7. 重构输出清单生成顺序。
   - `run_all.py` 只生成科学输出；`verify_outputs.py` 和第二次复现完成后，再由单独步骤从显式 allowlist 生成最终清单。
   - 不把 `output_manifest.json` 自身纳入自身哈希；若需要，使用外部签名/冻结清单承载其哈希。
   - 对 `<SOURCE_FILE_REDACTED>` 使用规范化单元格摘要；若要求字节一致，再固定 ZIP 成员时间戳和顺序。
   - 验收：从空输出目录运行两次，清单项集合相同、每项当前哈希匹配，状态 `pass`。

8. 统一冻结和知识来源元数据。
   - 将三张训练卡的 ID、文件哈希、状态、检索方式和 adopt/adapt 决策写入唯一权威列表。
   - 明确 `retrieval-log.json` 是自动检索为空，还是所有实际使用知识为空；两者不可混用。
   - 外部冻结步骤应记录实际 run command，并使下一版本的 `freeze_performed` 与冻结事实一致。
   - 验收：FROZEN、retrieval log、usage report 与 solution report 的卡片集合/冻结状态一致，状态 `pass`。

9. 增强真正独立的验证。
   - 保留本次审计采用的“从附件材料重新组装 ODE + Radau”基准，不调用主求解器构造矩阵。
   - Q2/Q3 验证从原始参数独立重建全网格，不能只读取主流程生成的 CSV 后取最小值。
   - 用结构化 claims 表把论文每个数值绑定到 YAML/CSV 字段、单位和允许舍入；取消数字子串存在测试。
   - 验收：故意交换结论、单位或上下文时校验会 `fail`，当前正确论文为 `pass`。

## P3：简化与交付质量

10. 说明空间网格选择。
    - 增加 18/27/36/54/72/108 状态的误差—耗时—厚度决策表。
    - 可用 27 状态执行快速选型，用 54 或更细网格生成最终温度场；两者决策一致性需 `pass`。

11. 完成论文编译检查。
    - 在有 XeLaTeX/latexmk 的受控环境编译 `paper/main.tex`，记录命令、版本、退出码和日志。
    - 检查六幅图、交叉引用、中文字体与附录路径。
    - 当前无 TeX 引擎，状态保持 `needs_review`；不得补写为 `pass`。

12. 收紧结论措辞。
    - Q1 可保留“内部数值与附件轨迹一致”。
    - Q2/Q3 在完成 P0—P1 前统一写为“给定初值、纯导热空气隙、固定等效边界参数和名义物性下的条件最优”。
    - 将名义厚度、确定性储备厚度和实验外部有效性并列表述，避免读者把复现 `pass` 理解为安全保证。

## 建议的下一版本完成门槛

- FROZEN、输入身份与输出清单：`pass`。
- 从空目录的两次语义复现：`pass`。
- 独立 ODE、稳态热阻、网格与优化复核：`pass`。
