# 冻结盲解自我差距分析

## 总体结论

冻结盲解在当前比较集中最强的是证据纪律、模型选择、独立数值验证和条件化结论；最明显的表达差距是缺少一个低阶 R–C 预算来直观解释“哪一层控制稳态隔热、哪一层控制瞬态延迟”。参考材料没有推翻冻结结果，但暴露了边界结构改变可令临界厚度相差数毫米，也提供了若干可吸收的解释与表达模式。综合状态为 `needs_review`，不修改冻结盲解。

## 3. 看参考后才形成的 candidate

### 3.1 层级 R–C 预算作为解释层

REF-01 与 REF-03 都强调 II 层主要延缓温升、IV 空气层主要提高隔热。独立计算支持这一解释：

- 标定工况四层导热热阻占比：I 2.59%、II 5.75%、III 28.36%、IV 63.30%。
- 标定工况面热容占比：I 2.14%、II 93.82%、III 3.98%、IV 0.05%。
- Q3 名义厚度下：II 占服装层面热容 97.99%，IV 占服装层导热热阻 62.10%。

冻结盲解已有四节点 RC 基线，但没有把逐层 $R_j=d_j/k_j$、$C_j=\rho_jc_jd_j$ 做成读者可见的解释预算。新增做法属于“已有低阶模型基础 + 参考触发的表达增强”，状态为 `candidate`。

### 3.2 边界结构极限对照

REF-01 使用双 Robin，REF-02/03 把外表面直接固定为环境温度。两类论文结果差异说明外侧 Dirichlet 可作为 $h_o\to\infty$ 的结构极限，而不能与有限 $h_o$ 混为同一模型。冻结盲解已经做空气隙结构压力，但没有单独报告外边界 Dirichlet 极限；将其加入“边界结构包络”属于参考后 candidate。

### 3.3 参考代码活性门禁

REF-03 中 `K` 未使用、皮肤边界节点未更新，显示“公式看似完整”不等于“实现中的参数和状态活着”。冻结验证强调自身输入与 claims，但复盘参考时还应新增：参数引用检查、目标节点更新时间检查、故意扰动参数后输出必须变化。该做法属于参考后 candidate。

### 3.4 临界约束表

REF-01 用“47℃约束临界厚度 / 44℃时长约束临界厚度 / 最终交集”的小表解释活跃约束，读者负担较低。冻结结果结构化更严谨，但正文可再加入一张同类表，将 Q2/Q3 两个约束对应的连续厚度并列。该表达模式属于参考后 candidate。

## 4. 冻结盲解相对参考材料的优势

1. **模型选择有基线和顺序验证。** 三篇参考均直接采用某个差分模型，没有同参数数目候选比较。
2. **双边界参数与数据分离更完整。** REF-02/03 的外表面 Dirichlet 是强结构假设；REF-03 甚至注入目标温度。
3. **数值复现层次更深。** 独立 Radau、解析热阻、全制造网格和语义 claims 超出参考材料的验证深度。
4. **把条件答案与工程保证分开。** 参考材料多用“最优”“确保”；冻结盲解明确限定初温、间隙结构、权重和名义物性。
5. **计算效率更好。** 54 状态特征分解避免 REF-01 的 270 万显式步，也避免 REF-02 的每候选逐秒追赶。

## 6. 不采纳的参考做法

- 不把全轨迹拟合误差当独立外部验证。
- 不把外表面 Dirichlet 和有限换热系数模型的厚度答案直接平均。
- 不把重拟合后参数变化小解释为辐射必然可忽略。
- 不使用只取最大正残差的“最大误差”。
- 不采纳未更新边界状态或未使用拟合参数的打印代码结果。
- 不因参考材料被称为优秀论文而将其状态自动设为 `pass`。
